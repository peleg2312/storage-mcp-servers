OpenManage Enterprise hardware requirements

This section provides recommended hardware requirements for OpenManage Enterprise appliances running with and without plugins in small and large deployments. For more information about plug-in hardware requirements, see the User's Guide of the respective OpenManage Enterprise plug-ins available on the support site.

Maximum recommended hardware configuration

OpenManage Enterprise appliance is shipped with the maximum recommended hardware requirements to provide you a hassle-free deployment and installation of the appliance and plug-ins respectively. However, if your environment doesn't require the maximum hardware configuration, see "Manage memory and CPU requirements based on deployment size" section in this Support Matrix to determine the appropriate hardware resources required for your specific requirements. The following table lists recommended hardware requirements for installing OpenManage Enterprise and all of its plug-ins:

Table 1: Maximum recommended hardware configuration
Hardware configuration Recommended configuration
RAM 64 GB
Processor cores 8
Hard drive space 830 GB
  • *The OpenManage Enterprise appliance is configured with two Virtual Drives (VDs), each with an initial storage drive space of 415 GB. The primary VD is leveraged for the core application and database, and the secondary VD is required for additional features and supporting plugins.
    NOTE:When deploying OpenManage Enterprise on OpenShift, the appliance boots and functions fully using the primary VD. No additional VDs are required.
  • *Ensure that your hypervisor storage has enough free space to support the recommended virtual drive size of the appliance, and enough overhead to support snapshots and future expansion of the virtual drive.
  • *Ensure that the primary drive and the secondary drive are always identical in storage capacity.
NOTE: OpenManage Enterprise now supports only monitoring featrues such as discovery, hardware inventory, health, and alert up to 25,000 devices. To operate at this scale, the OpenManage Enterprise appliance must be configured with 256 GB RAM and 64 CPU cores. No other features or plug-ins are supported at this scale. For more information, see the Recommended OpenManage Enterprise configuration for monitoring 25,000 devices section in the OME User's Guide available on the support site.

Plug-ins

Lists the supported plug-ins that can be enabled for additional OpenManage Enterprise monitoring and management capabilities.

Table 5: Plug-ins supported by OME
Plug-in Supported Versions Description
OpenManage Enterprise Services (Default plug-in) 4.6 Enables proactive and predictive monitoring and management support for devices with ProSupport and ProSupport Plus entitlements.
Update Manager 2.0 Enables administrators to create and manage repositories for PowerEdge devices with iDRAC or Windows that are managed in OpenManage Enterprise.
Dell AIOps (Default plug-in) 2.6 Enables administrators to register with the Dell AIOps, select the device groups for data transfer to Dell AIOps for proactive monitoring and measurement of overall health of the selected devices.

Operations Manager 1.7 Enables the monitoring of the Dell hardware assets that are discovered in OpenManage Enterprise using the System Center Operations Manager (SCOM) console.

Original Equipment Manufacturer (OEM) devices

NOTE: OpenManage Enterprise currently does not support OEM MX7000 chassis.

Dell OEM devices (rebranded or de-branded PowerEdge servers), when discovered, are classified under System Groups > All Devices > Servers > OEM Servers on the All Devices page. If both the server and DRAC of the OEM device are discovered, they are correlated and displayed as one device under the OEM Devices group. Most of the functionality available to the PowerEdge servers—such as tasks, reports, and filters—are also available to the PowerEdge OEM servers. However, system update may not be possible if it is not supported by the OEM device module.

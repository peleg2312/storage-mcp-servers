Adding a node

You can add a node by calling this API:

PUT /API/V1/Deployment{id}

To add a node, you need to:

  1. Get the current deployment for which you want to add a node.

  2. Edit the retrieved deployment object and use that as the payload for adding the node.

  3. Make these required edits:

    • Set scaleup: true and retry: true.

    • In the serviceTemplate, add a new component object (this will be the scale up node) by copying one of the current components with type: SERVER.

    • In the new component object, set the following fields to null:

      • identifier:
      • asmGUID:
      • puppetCertName:
      • osPuppetCertName:
      • managementIpAddress:

    • In the new component object, set the following fields with the specified values:

      • id: <unique uuid>
      • name: <unique name>
      • brownfield: false

    • For the new component object, edit the asm:server resource. Go through each parameter under that resource and set its value to null, but leave the following parameters as is:

      • razor_image
      • scaleio_enabled
      • scaleio_role
      • compression_enabled
      • replication_enabled

  4. Call PUT /Api/V1/Deployment/{id} with the newly created deployment object.

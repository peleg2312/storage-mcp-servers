Query the PowerFlex Gateway configuration (GET)

You can query the Gateway configuration at any time to verify whether the MDM IP addresses are configured:

https://<server_ip>:443/api/Configuration
GET

The response includes the following:

  • cipherSuites: List of names of cipher suites (as recognized by Java) that the SSL will use instead of the default list
  • featuresEnableCollectAutoLogs: Enable the Auto Collect Logs feature
  • featuresEnableIM: Indicates whether the PowerFlex Installer is enabled
  • featuresEnableSnmp: Indicates whether SNMP is enabled
  • keycloakHostUrl: Indicates internal keyloak service address
  • keycloakPublicClient: Indicates external keycloak service address
  • keycloakRealm: Indicates the security realm
  • mdmAddresses: List of MDM primary IP addresses that the PowerFlex Gateway will use to connect to the MDM
  • mdmUsername: MDM username
  • mdmPort: MDM port
  • snmpSamplingFrequency: MDM sampling frequency in seconds
  • systemId: ID of the system, configured by mdmAddresses.
  • upgradeSdrInMM: Indicates SDRs that were in maintenance mode during upgrade
  • upgradeSdtInMM: Indicates SDTs that were in maintenance mode during upgrade

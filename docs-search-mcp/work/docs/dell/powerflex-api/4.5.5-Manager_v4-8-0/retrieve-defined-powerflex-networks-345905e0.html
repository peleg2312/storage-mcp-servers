APIS > PowerFlex Manager Deployment REST API > bootstrapper > api > networks

Retrieve defined PowerFlex networks

Returns an ordered list of configured networks. The PowerFlex management network displays first, followed by Data1, Data2, and so on.

Responses
200 : OK

Collection of all configured networks.

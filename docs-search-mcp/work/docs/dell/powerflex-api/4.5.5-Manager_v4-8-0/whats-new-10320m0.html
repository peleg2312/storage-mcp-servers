Getting Started > PowerFlex Manager API (4.8.x)

What’s new

The following update is made for PowerFlex Manager 4.8.x:

A PowerFlex Manager Deployment REST API is added that starts a deployment workflow based on the configuration settings choosen.
The PowerFlex Manager Deployment REST API is designed to provide initial configuration and essential system information required to start interacting with the platform.

The following APIs were deprecated in PowerFlex Manager 4.8.x:

  • /corelcm/uploadSignedCertificate
  • /corelcm/csr

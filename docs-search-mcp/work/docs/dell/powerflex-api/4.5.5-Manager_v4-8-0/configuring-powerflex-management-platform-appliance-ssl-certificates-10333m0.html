Configuring PowerFlex management platform appliance SSL certificates

You must configure SSL certificates on the PowerFlex Management Platform appliance to ensure secure, trusted, and encrypted communication for the PowerFlex Manager user interface and integrations, and to replace the default self‑signed certificate with one that meets enterprise security and certificate‑chain requirements.

Prerequsites

Before calling an endpoint, you must first authenticate and generate an access token. This is done by using the following operation:
POST /rest/auth/login

After a successful login, the API returns a JSON response containing an access token.
Store this token in a variable (for example, ACCESS_TOKEN) for use in subsequent API calls.

1. Create the certificate signing request (CSR)

The operaton you must use is: POST /rest/v1/security-settings/0/generate-ingress-csr

The request body is:

curl  -i --insecure -X POST "https://${INGRESS_IP_OR_HOSTNAME}:443/rest/v1/security-settings/0/generate-ingress-csr" -H "accept: application/json"  \
-H "Content-Type: application/json" -H "Authorization: Bearer ${ACCESS_TOKEN}" \
-d '{"common_name": "dellpowerflex3.com","organizational_unit": "PowerFlex","organization": "Dell","country": "US","state": "CA","locality": "San Jose"}' | awk  '{gsub("\\\\n","\n")};1'

The expected common name is the hostname for the STRINGENT certificate generation:

{"common_name": "dellpowerflex.com", "organizational_unit": "PowerFlex", "organization": "Dell", "country": "US", "state": "CA", "locality": "San Jose"}

The expected common name is the IP address for the STANDARD certificate generation:

{"common_name": "100.68.101.116", "organizational_unit": "PowerFlex", "organization": "Dell", "country": "US", "state": "CA", "locality": "San Jose"}

2. Generate the SSL certificate and trusted Certificate Authority

The CSR generated above must be used to create a valid TLS certificate and trusted CA, which are then uploaded to the PowerFlex management platform appliance.

3. Upload the ingress certificate

The request body is:

curl -F "sslCertificateFile=@/tmp/certificate.pem" \
-i --insecure -X POST "https://${INGRESS_IP_OR_HOSTNAME}:443/rest/v1/security-settings/0/upload-ingress-certificate" \
-H "Authorization: Bearer ${ACCESS_TOKEN}"

4. Upload the Certificate Authority

The request body is:

curl  -F "file=@/tmp/ca.pem" -F "name=TrustedCA" -i --insecure --request POST \
  --url https://${INGRESS_IP_OR_HOSTNAME}/Api/V1/ui/lcm/uploadssltrustedcert \
  --header 'Content-Type: multipart/form-data' \
  -H "Authorization: Bearer ${ACCESS_TOKEN}"

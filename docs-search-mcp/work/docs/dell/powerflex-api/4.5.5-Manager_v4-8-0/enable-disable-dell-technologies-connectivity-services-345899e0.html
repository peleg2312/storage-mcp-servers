APIS > PowerFlex Manager Deployment REST API > bootstrapper > api > secure-connect

Enable / Disable Dell Technologies connectivity services

Enables or disables Dell Technologies connectivity services based on the requested payload {enabled: true} - to enable
{enabled: false} - to disable. This step in the workflow is updated to a “Completed” status irrespective of whether you enable or disable.

Requests
Path Parameters
id
string Required
Request Body
enabled
boolean

true: if everything validated and successful.
false: if skipped

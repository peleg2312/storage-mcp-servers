Getting Started > PowerFlex Power API (4.5.5)

What’s new

The following updates were made for PowerFlex Power APIs 4.5.5.

Two PowerFlex PowerAPIs are added for the following features:

Feature name YAML file name Description
Fully Qualified Domain Name - only certificates PowerFlex Security Engine REST API 1.0 Includes the APIs to manage security including certificate management.
Management Diagnostics PowerFlex Maintenance Manager REST API 1.0 Includes the APIs to retreive the status of PowerFlex Manager nodes and pods, and to run diagnostics on the PowerFlex Management Platform.

Note: To view the YAML files mentioned in the table, go to https://developer.dell.com/.

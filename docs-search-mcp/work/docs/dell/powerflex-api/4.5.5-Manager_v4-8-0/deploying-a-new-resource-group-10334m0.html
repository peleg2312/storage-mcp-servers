Deploying a new resource group

To create a resource group from a template, you need to:

  1. Retrieve the template with GET /Api/V1/ServiceTemplate/{id}?forDeployment=true.

  2. Create the JSON for a deployment object and set deploymentName and useDefaultCatalog = true (if you want to use the appliance default catalog). Also, set updateServerFirmware = true and set serviceTemplate to the template retrieved in step 1. If you want to use a different catalog other than the appliance default, specify useDefaultCatalog = false and set firwmareRepositoryId = the id of the RCM, catalog, or firmware repository that you want to use for the new resource group deployment.

  3. Modify the template. For any components that have instances > 1, you need to create a separate component for each desired instance. In other words, if the component has 3 instances, you should clone it to create 3 top-level components. Each component must have a unique id and the associatedComponents map must be updated to reflect the newly created component ids.

  4. Start the resource group with POST /Api/V1/Deployment.

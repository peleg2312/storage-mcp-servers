Introduction

Introduction to PowerFlex

PowerFlex is an enterprise-class, software-defined block storage solution that is deployed, managed, and supported as a single system. Highly flexible and scalable, PowerFlex allows customers to mix two-layer (Server SAN), single-layer, and storage-only and mixed architectures within a single deployment.

PowerFlex API

The PowerFlex API is installed as part of the PowerFlex Installation Manager/PowerFlex Gateway package. The Installation Manager manages deployment and upgrades. The PowerFlex Gateway leverages role-based security access to expose RESTful APIs for automating all frontend and backend storage tasks and core components, and also acts as a gateway for SNMP traps and SRS.

The REST API is served from the PowerFlex Gateway through the REST gateway. The PowerFlex Gateway connects to a single MDM (metadata manager) and serves requests by querying the MDM and reformatting the answers it receives from the MDM in a RESTful manner back to a REST client. Every PowerFlex SCLI command is also available in the PowerFlex REST API. The responses returned by the PowerFlex Gateway are in JSON format.

The current API version is 3.6. APIs may change as new features are added to the product or changes are made to the PowerFlex software.

Target audience

The PowerFlex REST API is intended for customers who want to automate PowerFlex deployment, configuration, and management tasks.

Basic concepts

The following basic concepts are relevant to understanding and operating PowerFlex.

Concept Description
MDM Meta Data Manager. The MDM configures and monitors PowerFlex, and is usually configured in redundant cluster mode to support high availability.
SDC Storage Data Client. The SDC is a lightweight device driver that exposes PowerFlex volumes as block devices to the application that resides on the same server on which the SDC is install.
SDS Storage Data Server. The SDS manages the capacity of a single server and acts as a backend for data access.
Protection Domain A logical entity that consists of a group of SDSs that backs up each other
Fault Set A logical entity that contains a group of SDSs that are more inclined to go offline simultaneously
Storage Pool A set of physical storage devices in a Protection Domain. A volume is distributed over all devices residing in the same Storage Pool.
Acceleration Pool A group of one or more physical acceleration devices.
Volume Consists of multiple storage blocks spread evenly across Storage Pool devices.
Snapshot An image-level view of data at a particular point in time
SDR Storage Data Replicator, which processes the application I/Os of the source SDRs

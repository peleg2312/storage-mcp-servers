Receiving responses from the notification API

When receiving a response from the notification service REST API, note that the response will be held in a key:value dictionary under the key “results”.

The following APIs use the `“results” key:

  • /rest/v1/dispatch-sources
  • /rest/v1/dispatch-destinations
  • /rest/v1/dispatch-policies
  • /rest/v1/syslogs
  • /rest/v1/support-assist-config

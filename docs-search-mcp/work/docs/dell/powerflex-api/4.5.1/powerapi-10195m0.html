Introduction to Power API

PowerAPI is a standard defined for REST API. The APIs are compliant with OpenAPI Specification (OAS) 3.0.0.

PowerAPIs are available for the following features in PowerFlex 4.5.x release:

Feature name YAML file name on the Dell Developer Portal Description
Authentication auth 1.0 Includes APIs for login, logout and refresh token.
SSO PowerFlex SSO REST API 1.0 Includes APIs for user operations, roles, groups, login banners, and directory services.
Alerts PowerFlex Alerts REST API 1.0 Includes APIs for managing alerts and alert templates.
Events PowerFlex Events REST API 1.0 Iincludes APIs for managing events.
Notifier Notifier API Swagger UI 3.0.3 Includes APIs for configuring and modifying external source and destination to receive an external event , adding and modifying notification policies, support assist configuration, and Email (SMTP) services.
File services PowerFlex NAS Management REST API 1.0.0 Includes APIs for managing file services.

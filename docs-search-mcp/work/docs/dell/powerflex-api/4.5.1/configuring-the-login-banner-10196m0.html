Configuring the login banner

To configure the login banner, run the following API commands:

  • Get login banner by ID

    GET https:///rest//login-banners/{id}

  • Get login banner

    GET https:///rest//login-banners/

  • Get login banner text

    GET https:///rest//login-banners/text

  • Add login Banner

    POST https:///rest//login-banners/

To modify the login banner, run the following API command:

PATCH https:///rest//login-banners/{id}

To delete the login banner, run the following API command:

DELETE https:///rest//login-banners/{id}

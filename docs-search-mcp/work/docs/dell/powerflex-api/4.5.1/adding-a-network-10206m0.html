Adding a network

You can add a network by calling this API:

POST /Network

Sample request body:

{
    "description": "Workload/Customer",
    "name": "vcesys-customer-1101",
    "static": false,
    "type": "PUBLIC_LAN",
    "vlanId": 1101
}

Sample response:

{
    "createdBy": "admin",
    "createdDate": "2021-05-17T19:35:29.233Z",
    "description": "Workload/Customer",
    "destinationIpAddress": null,
    "id": "ff808081797ad05001797bd380d20221",
    "link": null,
    "name": "vcesys-customer-1101",
    "static": false,
    "staticNetworkConfiguration": null,
    "type": "PUBLIC_LAN",
    "updatedBy": null,
    "updatedDate": null,
    "vlanId": 1101
}

Getting a credential

You can get a specific credential by calling this API with a filter that specifies a label:

GET /Credential?filter=eq,label,AER%20VxFlex%20OS

Sample response:

<?xml version="1.0" encoding="UTF-8" standalone="yes"?>
<credentialList>
  <credential>
    <link href="getCredential/957e69fd-d674-439a-8e06-82c7f670e349" rel="self" title="AER VxFlex OS"/>
    <OSCredential>
      <id>957e69fd-d674-439a-8e06-82c7f670e349</id>
      <label>AER VxFlex OS</label>
      <username>root</username>
      <createdBy>admin</createdBy>
      <createdDate>2021-05-17T19:36:56.599Z</createdDate>
      <updatedBy>admin</updatedBy>
      <updatedDate>2021-05-17T19:36:56.604Z</updatedDate>
    </OSCredential>
    <references>
      <devices>0</devices>
      <policies>0</policies>
    </references>
  </credential>
  <totalRecords>1</totalRecords>
</credentialList>

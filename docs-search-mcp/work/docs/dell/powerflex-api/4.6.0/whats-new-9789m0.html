Getting Started > PowerFlex Manager API (4.6.0)

What’s new

The following updates were made for PowerFlex Manager 4.6.

  • Added new APIs for the following:

    • Core LCM
      • POST /corelcm/validateUpgrade
      • POST /corelcm/validatePowerFlex
      • POST /corelcm/validateAppliance
      • POST /corelcm/restorenow
      • POST /corelcm/importPFXM
      • POST /corelcm/disconnectMDM
      • POST /corelcm/connectMDM
      • POST /corelcm/configureBootStrap
      • POST /corelcm/backupNow
      • POST /corelcm/backupNowWithSettings
      • GET /corelcm/status
      • POST /corelcm/healthz
      • POST /corelcm/getBackupSchedule
    • Certificate
      • POST /corelcm/uploadeTrustedCertificate
      • POST /corelcm/uploadSignedCertificate
      • POST /corelcm/delSSLCerts
      • POST /corelcm/
      • GET /corelcm/trustedcertinfo
      • GET /corelcm/trusted
      • GET /corelcm/certinfo

  • Removed the following APIs:

    • Appliance

      • PUT /Appliance/applianceStatus
      • GET /Appliance/upgradeStatus
      • POST /Appliance/applianceReboot
      • GET /Appliance/asmVersion

    • AlertConnector

      • All endpoints

  • Changed /Appliance/applianceStatus to /Appliance/status

  • Changed /Appliance/update to /Appliance/upgrade

  • Added a new article about performing non-disruptive upgrade operations

What’s new

PowerFlex Manager version 4.0 includes the following new APIs:

  • APIs for components:

    • GET /component/{id}
    • PUT /component/{id}
    • GET /component with filtering capabilities

  • APIs for volumes:

    • GET /volumes/volume/{id}
    • GET /volumes/volume with filtering capabilities
    • GET /volumes/volume/findAvailableSequences

  • APIs for datastores:

    • GET /volumes/datastore/{id}
    • GET /volumes/datastore with filtering capabilities
    • GET /volumes/datastore/findAvailableSequences

  • APIs for resource groups:

    • GET /resourcegroup/{id}
    • POST /resourcegroup/template/{templateId}/avaiablenodes
    • GET /resourcegroup with filtering capabilities

  • APIs for devices:

    • GET /device/{id}
    • GET /device with filtering capabilities

  • APIs for nodepools:

    • GET /nodepool/{id}
    • GET /nodepool with filtering capabilities

  • APIs for templates:

    • GET /template/{id}
    • GET /template with filtering capabilities

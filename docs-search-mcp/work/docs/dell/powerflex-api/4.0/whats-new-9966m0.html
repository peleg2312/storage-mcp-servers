What’s new

The following updates are included in the PowerFlex 4.0 release:

  • Added new APIs for the following:

    • RunLiaOsPatching

      POST /im/types/Configuration/actions/liaRunOsPatching

    • CollectLogs

      POST /im/types/NodeInfo/instances/actions/collectLogs

    • addMappedHost

      POST /api/instances/Volume::{id}/action/addMappedHost

    • removeMappedHost

      POST /api/instances/Volume::{id}/action/removeMappedHost

    • SDT

      • GET /api/types/Sdt/instances
      • GET /api/types/Sdt/instances?systemId={system id}&sessionTag={session tag}&lastVersion={last version}
      • GET /api/instances/Sdt::{id}
      • GET /api/instances/Sdt::{id}/relationships/Statistics
      • POST /api/types/Sdt/instances/action/querySelectedStatistics
      • POST /api/types/Sdt/instances/action/queryIdByKey
      • POST /api/types/Sdt/instances/action/queryBySelectedIds
      • POST /api/instances/Sdt::{id}/action/removeSdt
      • POST /api/types/Sdt/instances
      • POST /api/instances/Sdt::{id}/action/renameSdt
      • POST /api/instances/Sdt::{id}/action/modifyIpRole
      • POST /api/instances/Sdt::{id}/action/modifyStoragePort
      • POST /api/instances/Sdt::{id}/action/modifyNvmePort
      • POST /api/instances/Sdt::{id}/action/modifyDiscoveryRole
      • POST /api/instances/Sdt::{id}/action/addSdtIp
      • POST /api/instances/Sdt::{id}/action/removeIp
      • POST /api/instances/Sdt::{id}/action/enterMaintenanceMode
      • POST /api/instances/Sdt::{id}/action/exitMaintenanceMode

  • The following new properties are added to the SDC model:

    • hostType
    • nqn
    • maxNumPaths
    • hostOsFullType
    • sdtId
    • cantConnectToSomeSdss
    • maxNumSysPorts

    Note: SDCs now represent NVMe host also.

  • The new property value NvmeIni is added for property sdcType in SDC model.

  • Volume managedBy and replicationJournalVol properties are replaced by volumeClass.

  • addMappedSdc is replaced by addMappedHost.

  • The new property spClass is added to the StoragePool.

  • The following new properties are added to the Snapshot Policy model:

    • rcgId
    • rcgName
    • lastAutoSnapshotDataTime
    • isLastAutoSnapshotDataTimeAccurate

  • The following new properties are added to Replication Pair model:

    • (destinationStoragePoolId)
    • (destinationSdcId)
    • (destinationSdcGuid)
    • (volumeAccessMode)
    • (allowMultiMap)
    • (compressionMethod)
    • (volumeType)
    • (useRmcache)
    • (directBufferMapping)
    • (informSdc)
    • (forceAsync)
    • (allowMultipleMappings)

Note: The properties in brackets are only available when creating ReplicationPair and do not appear when retrieving it.

  • Replaced allowOnExtManagedVol with volumeClass in the following operations:
    • /api/instances/System::{id}/action/snapshotVolumes
    • /api/instances/System::{id}/action/removeConsistencyGroupSnapshots /api/instances/Volume::{id}/action/setVolumeSize
    • /api/instances/Volume::{id}/action/removeVolume
    • /api/instances/Volume::{id}/action/setVolumeName
    • /api/instances/Volume::{id}/action/addMappedHost
    • /api/instances/Volume::{id}/action/addMappedSdc
    • /api/instances/Volume::{id}/action/addMapForReplicationOfflineCopy
    • /api/instances/Volume::{id}/action/removeMappedSdc
    • /api/instances/Volume::{id}/action/overwriteVolumeContent
    • /api/instances/Volume::{id}/action/removeMappedHost
    • /api/instances/Volume::{id}/action/migrateVTree

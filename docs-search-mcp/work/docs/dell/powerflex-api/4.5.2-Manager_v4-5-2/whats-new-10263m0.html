Getting Started > PowerFlex Block API (4.5.2)

What’s new

The following updates are included in the PowerFlex 4.5.x release:

  • Added new APIs for the following:

    • SnapShotCopyTask
      • GET /api/types/SnapshotCopyTask/instances
      • GET /api/instances/SnapshotCopyTask::{id}
      • GET /api/types/SnapshotCopyTask/instances
      • POST /api/instances/SnapshotCopyTask/action/removeSnapshotCopyTask
      • POST /api/instances/SnapshotCopyTask/action/pauseSnapshotCopyTask
      • POST /api/instances/SnapshotCopyTask/action/resumeSnapshotCopyTask
      • POST /api/types/SnapshotCopyTask/instances/action/queryBySelectedIds

  • System Network

    • GET /api/types/SystemNetwork/instances
    • GET /api/types/ SystemNetwork /instances?systemId={system id}&sessionTag={session tag}&lastVersion={last version}
    • GET /api/instances/ SystemNetwork::{id}
    • POST /api/instances/ SystemNetwork::{id}/action/removeSdt
    • POST /api/types/ SystemNetwork /instances
    • POST /api/instances/ SystemNetwork::{id}/action/ renameSystemNetwork

  • Host Group

    • GET /api/types/HostGroup/instances
    • GET /api/types/HostGroup/instances?systemId={system id}&sessionTag={session tag}&lastVersion={last version}
    • GET /api/instances/ HostGroup::{id}
    • POST /api/instances/ HostGroup::{id}/action/removeHostGroup
    • POST /api/types/HostGroup /instances
    • POST /api/instances/ HostGroup::{id}/action/modifyHostGroup
    • POST /api/instances/ HostGroup::{id}/action/ renameHostGroup
    • POST /api/instances/ HostGroup::{id}/action/assignHostToHostGroup
    • POST /api/instances/ HostGroup::{id}/action/removeHostFromHostGroup

  • Remote system

    • GET /api/types/RemoteSystem/instances
    • GET /api/instances/RemoteSystem::{id}
    • POST /api/types/RemoteSystem/instances
    • POST /api/instances/ RemoteSystem::{id}/action/modifyRemoteSystemDescription
    • POST /api/instances/ RemoteSystem::{id}/action/renameRemoteSystem
    • POST /api/instances/ RemoteSystem::{id}/action/modifyRemoteSystemConnectivity
    • POST /api/instances/RemoteSystem::{id}/action/removeRemoteSystem
    • POST /api/instances/RemoteSystem::{id}/action/testRemoteSystemConnectivity
    • POST /api/instances/RemoteSystem/action/modifyRemoteSystemBwLimit

  • Protection domain

    • POST /api/instances/ProtectionDomain::{id}/action/queryNvmeDiscoveryInfo

  • SDC

    • GET /api/types/Sdc/instances/action/queryAllSdcSupportingAutomaticUpdate
    • GET /api/types/Sdc/instances/action/queryAllSdcWithMdmIpUpToDate

  • Volume

    • POST /api/instances/Volume/action/modifyVolumeClass

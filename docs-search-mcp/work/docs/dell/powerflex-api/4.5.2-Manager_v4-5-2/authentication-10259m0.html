Authentication

All API requests require OAUTH2 access tokens for command authorization.

Every API call to PowerFlex must have an access token as a bearer authorization header except for the login and refresh token operations.
The login and refresh token operations uses the OIDC protocol.

Authorization: Bearer <insert access token here>

Example (Get all PowerFlex users):

curl --location --request GET 'https://powerflex-12.example.com/rest/v1/users' \
--header 'Accept: application/json' \
--header 'Content-Type: application/json' \
--header 'Authorization: Bearer eyJhbG...PSWkQ' \
--data-raw ''

Log in to PowerFlex

Request

POST https://<host>/rest/auth/login

The request should contain the username and password in the payload.

Response

The response includes the following parameters:

Response attribute Meaning
access_token Use this access token for consequent calls to the system.
expires_in An access token has an expiration date. The access token is valid only for 5 minutes. To continue accessing the system after the token expires, you can either update the token using standard OIDC refresh operation, or log in again to get a new access token.
refresh_token OIDC allows you to refresh a token and fetch a new access token without logging in again (with username and password). This refresh token can only be used once to refresh the current session. Once you refresh or log in again, you will get a new refresh token, and the old refresh token becomes invalid.
refresh_expires_in A refresh token has an expiration date. The refresh token is valid only for 30 minutes.

Example:

curl --location --request POST 'https://powerflex-12.example.com/rest/auth/login' \
--header 'Accept: application/json' \
--header 'Content-Type: application/json' \
--data-raw '{
    "username": "davidr",
    "password": "hf443!!e"
}'

RESPONSE:

{
    "access_token": "eyJhbG...Mudw",
    "expires_in": 300,
    "refresh_expires_in": 1800,
    "refresh_token": "eyJhbG...0fKrcMEE",
    "token_type": "bearer",
    "id_token": "eyJhbGciO...FKNw",
    "not-before-policy": 0,
    "session_state": "cc2c3f61-6cc7-4c9d-b75f-0c9889eb938e",
    "scope": "openid profile email"
}

Log out

REQUEST

POST https://<host>/rest/auth/logout

The request should contain the access token for authentication and the refresh token that you have received during login or refresh operation.

Note: For PowerFlex block, you can use the old login method. However, the old logout method is not supported.

Example

curl --location --request POST 'https://powerflex-12.example.com/rest/auth/logout' \
--header 'Accept: application/json' \
--header 'Content-Type: application/json' \
--header 'Authorization: Bearer eyJhbGciOi...-AouAgQ' \
--data-raw '{
    "refresh_token": "eyJhbGc...lOROrc"}'

Refresh access token

Request

POST https://<host>/rest/auth/update-token

Access token is not required for refresh operation. Use the refresh token that you have received during login and refresh operations in payload.

Example:

curl --location --request POST 'https://powerflex-12.example.com/rest/auth/update-token' \
--header 'Content-Type: application/json' \
--header 'Accept: application/json' \
--data-raw '{
    "refresh_token": "eyJh...C7QN0"
}'

Response:

{
    "scope": "openid profile email",
    "access_token": "eyJhb...II1SxPBA",
    "expires_in": 300,
    "refresh_expires_in": 1800,
    "refresh_token": "eyJhb...3QKhM",
    "token_type": "Bearer",
    "id_token": "eyJhbG...LhhhCUg",
    "session_state": "54ff7171-5311-43fb-aa4c-ce5a5076268f"
}

Note: The default session timeout value is 15 minutes. The session will be terminated after the timeout duration.

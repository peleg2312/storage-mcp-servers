Register connected licensing

Register the system with Dell dynamic licensing during initial system setup. This attaches the system
to the appropriate reservation pool on the online licensing system.

Additionally, it may also be used to
add a license directly to the system. However, if multiple systems share the same reservation pool,
the new license entitlements will be distributed across all systems within that pool.

Requests
Request Body
LicensesConfigRegisterConnectedLicensing
object

To configure connected licensing, you must specify at least one License Authorization Code (LAC). If you don’t, a trial license will automatically begin.

lac
array[string]

A list of License Authorization Codes (LACs).

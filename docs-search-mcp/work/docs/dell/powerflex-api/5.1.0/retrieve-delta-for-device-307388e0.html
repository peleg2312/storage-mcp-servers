Retrieve delta for device

Returns changes in the devices since the last call of this query.

To begin querying deltas, use sessionTag=0 and lastVersion=0.

For subsequent queries, use values returned by the previous query.

Requests
Query Parameters
system id
string

Identifies the system context for which you want device instances.

session tag
string Required

Associates the request with a specific session or transaction

last version
string Required

Indicates whether to fetch the latest version of the device instances or a previous one.

Responses
200 : OK

OK

Response Body
object

An object that contains data regarding the changes that occurred in the Device objects in the cluster since the last request, as well as data regarding how to send the next query.

sessionTag
number

The session in which communication with the MDM regarding the delta is done. It is echoed back to the MDM in the next call within this session. Use 0 for the initial call.

isDirty
boolean

TRUE indicates that changes to the data queried occurred during the processing of the request. These changes may or may not be reflected in the response. Depending on the use case, sending an additional query to check for missed changes may be advisable.

lastDeviceVersion
number

Identifier within the session to be used in the next call. Use 0 in the initial call.

deviceIsPartial
boolean

TRUE indicates that only partial data was sent due to the response size passing the threshold defined in MDM. The remaining data should be retrieved using another query with the sessionTag + lastDeviceVersion values returned by this query.

deviceList
array[object]

List of added or modified Device objects since the last query. In case of a full response (deletedDeviceIdList = null), this list contains all the Device objects that currently exist (unless deviceIsPartial = true, in which case this list is a subset of all currently existing Device objects).

deletedDeviceIdList
array[string]

List of IDs of deleted Device objects since the last query. If the list is null (unlike an empty list), it means that the response contains all instances of Device objects; any Device objects not included in this response should be considered as deleted.
NOTE: This attribute may be set in conjunction with the deviceIsPartial attribute, in which case only Device objects that are not present in this response and any of the subsequent responses until a non-partial response was received were actually deleted. If your use-case is sensitive to bursts of delete-and-re-create events, this should be taken into account.

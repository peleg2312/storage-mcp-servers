Erasure coding APIS > PowerFlex Block REST API > Volume

Map a volume to one or all SDC/NVMe hosts

Map a volume to one or all SDC or NVMe nodes. This exposes a volume to all SDC or NVMe nodes.

The exposure includes the SDC or NVMe hosts that will be added after the request is run.

Retrieve delta for volume

Returns changes in Volumes since the last call of this query.

To begin querying deltas, use sessionTag=0 and `lastVersion=0``.

For subsequent queries, use values returned by the previous query.

Requests
Query Parameters
system id
string Required
session tag
string Required
last version
string Required
Responses
200 : OK

OK

Response Body
Volume_Delta
object

An object that contains data regarding the changes that occurred in volume objects in the cluster since the last request, and data regarding how to send the next query.

sessionTag
number

The session in which communication with the MDM regarding the delta is done. It is echoed back to the MDM in the next call within this session. Use 0 for the initial call.

isDirty
boolean

TRUE indicates that changes to the data queried occurred during the processing of the request. These changes may or may not be reflected in the response. Depending on the use case, sending an additional query to check for missed changes may be advisable.

lastVolumeVersion
number

Identifier within the session to be used in the next call. Use 0 in the initial call.

volumeIsPartial
boolean

TRUE indicates that only partial data was sent due to the response size passing the threshold defined in MDM. The remaining data should be retrieved using another query with the sessionTag + lastVolumeVersion values returned by this query.

volumeList
array[object]

List of added or modified volume objects since the last query. In case of a full response (deletedVolumeIdList = null), this list contains all the Volume objects that currently exist (unless volumeIsPartial = true, in which case this list is a subset of all currently existing Volume objects).

childVolumeIds
array[object]

A list of identifiers that reference subordinate or nested volume objects within a parent volume.

numOfChildVolumes
integer

The total number of child volumes associated with a parent volume object.

descendantVolumeIds
array[object]
numOfDescendantVolumes
integer

The total number of volume objects that are hierarchically nested under the current volume, including both direct children and all deeper nested descendants.

numOfMappedSdcs
integer

Indicates the number of storage data clients (SDCs) that are mapped to the volume object.

registrationKey
integer

A unique identifier or token used to authenticate, activate, or associate a volume object with a specific system.

registrationType
integer
deletedVolumeIdList
array[string]

List of IDs of deleted Volume objects since the last query. If the list is null (unlike an empty list), it means that the response contains all instances of Volume objects; any Volume objects not included in this response should be considered as deleted.
NOTE: This attribute may be set in conjunction with the volumeIsPartial attribute, in which case only Volume objects that are not present in this response and any of the subsequent responses until a non-partial response was received were actually deleted. If your use-case is sensitive to bursts of delete-and-re-create events, this should be taken into account.

Mirroring APIS > PowerFlex Manager REST API > Datastores

List volumes for the specified filter

Requests
Query Parameters
filter
string Required

Required filter. Must include at least vcenter ID: (vcenterId eq vcenter-100.68.77.215). Also all columns from Datastore are available i.e. name, id etc. Search Operators: eq (equals), ne (not equal), ge (greater than equal), le (less than equal), gt (greater than), lt (less than), like, ilike, sw (starts with), ew (ends with), in, empty, notempty, null, notnull, and, or, not example of parent level filter: (vcenterId eq vcenter-100.68.1.1) and (datacenterId eq datacenter-2) and (name eq datastore-1) example of child level filter: (volume.sizeInKb gt 16)

order
string

Valid sort columns are the same as in Datastore: name, id, etc

offset
string

Specify pagination offset

limit
string

Specify page limit

Getting started with the PowerFlex Manager Deployment

There are three major steps to get started with the deployment.

1. Create the configuration file

The endpoint accepts either an empty payload or an initial configuration file.

To create either an empty payload or an initial configuration file, use the following endpoint:
/rest/v1/bootstrapper/workflow-configuration

Depending on the input, a blank workflow or a workflow with predefined data is created.

2. Set up the workflow

To set up the workflow, the following steps must be completed:

  1. Enable Dell Technologies connectivity services: /rest/v1/bootstrapper/secure-connect Note: This step can be skipped and completed later.
  2. Ensure compliance: /rest/v1/bootstrapper/compliance Note: This step can be skipped and completed later.
  3. Define the network requirements: /rest/v1/bootstrapper/network-configuration, /rest/v1/bootstrapper/networks, /rest/v1/bootstrapper/network-environment/{id}
  4. Connect the installer node:
    • Set up installer node: /rest/v1/bootstrapper/installer-node/
    • Deployment: /rest/v1/bootstrapper/installer-node/{id}/deploy
  5. Build the deployment: /rest/v1/bootstrapper/build-deployment
    • Set up nodes: /rest/v1/bootstrapper/nodes
    • Switches: /rest/v1/bootstrapper/switches
  6. Add IP addresses: /rest/v1/bootstrapper/nodes

3. Start the deployment

Once the deployment is started, the workflow configuration cannot be changed.

To start the deployment, use the following endpoint:
/rest/v1/bootstrapper/workflow-configuration/{id}/deploy

To track the deployment, use the following endpoints:
/rest/v1/bootstrapper/workflow-configuration/{id}/deploy-status
/rest/v1/bootstrapper/workflow-configuration/{id}/deploy-logs

To download the logs file, use the following endpoint:
/rest/v1/bootstrapper/workflow-configuration/{id}/download-logs

Complete the deployment

Once the deployment is successfully completed, the following endpoint should be called to finalize the deployment and enable the PowerFlex Manager user interface:
/rest/v1/bootstrapper/workflow-configuration/{id}/complete

Notes:

  • It is mandatory to keep the order of steps 2.3 to 2.6
    (e.g., the Connect installer node step cannot be completed before the Define networks requirements step).

  • The Enable Dell Technologies connectivity services (p. 2.1.) and Ensure Ccompliance (p.2.2) steps can be completed at any time before the deployment is started.

  • At any point, the GET /rest/v1/bootstrapper/workflow-configuration request returns the current state of the workflow configuration, including the metadata of each step.

  • GET endpoints without {id} will return a collection. If the configuration workflow is not created, the collection will be empty. Once the workflow is created, the endpoints return a collection containing one element.

Migrate node OS

Migrate a node’s operating system from CentOS to SLES and return the job name.

Requests
Request Body
NodeOSMigrationRequest
object

Node OS migration request

deploymentId
string Required

Deployment identifier

example: 8aaa11328acdf8ce018ad1426ee07992
deviceIdList
array[string]

List of device identifiers

serviceModeOption
string

Service mode option

example: protected
allowed values: instant protected
Responses
200 : OK

OK

Response Body
NodeOSMigrationResponse
object

Response for the Node OS migration request

jobName
string

Key for the NodeOSMigrationJob

example: Job-c74a674d-41e2-464d-9b49-d88eda3a30a2

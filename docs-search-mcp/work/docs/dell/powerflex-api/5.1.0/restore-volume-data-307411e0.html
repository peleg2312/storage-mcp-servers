Erasure coding APIS > PowerFlex Block REST API > Volume

Restore volume data

Restores the volume data from one of it’s directly related snapshots.

Requests
Path Parameters
id
string Required

The id is the target volume to be restored.

Request Body
snapshotId
string

The ID of the snapshot to restore from.

Responses
200 : OK

OK

Response Body
Volume_object
object
childVolumeIds
array[object]

A list of identifiers that reference subordinate or nested volume objects within a parent volume.

numOfChildVolumes
integer

The total number of child volumes associated with a parent volume object.

descendantVolumeIds
array[object]
numOfDescendantVolumes
integer

The total number of volume objects that are hierarchically nested under the current volume, including both direct children and all deeper nested descendants.

numOfMappedSdcs
integer

Indicates the number of storage data clients (SDCs) that are mapped to the volume object.

registrationKey
integer

A unique identifier or token used to authenticate, activate, or associate a volume object with a specific system.

registrationType
integer

Query LIA security mode

Queries the security mode of the LIA (Lightweight Installation Agent) running on a specified node.

Requests
Request Body
nodeIp
string Required

The IP address of the node whose LIA security mode should be queried. Must be non-null and non-empty.

Responses
202

Accepted

Response Body
securityMode
string Required

The detected LIA security mode on the target node.
For example, “MTLS”, “NON_MTLS”, “NOT_ACCESSIBLE”.

MTLS
string

LIA is accessible and in mTLS mode. The security bootstrap process is completed on this node.

NON_MTLS
string

LIA is accessible but not in mTLS mode . The security bootstrap process is not started on this node.

NOT_ACCESSIBLE
string

The LIA cannot be reached. Verify that the agent is installed and running, and check network connectivity to the node.

400 : Bad Request

Bad Request - Missing or empty nodeIp.

Response Body
nodeIP
string Required

If the node IP address is null or empty, the following error message is returned: “The node IP address is missing”.

401 : Unauthorized

Unauthorized. Authentication failed because the required credentials were not provided or are invalid.

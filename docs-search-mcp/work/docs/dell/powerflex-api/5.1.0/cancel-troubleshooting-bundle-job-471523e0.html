Erasure coding APIS > PowerFlex Manager (AsmManager) REST API > Troubleshooting Bundle

Cancel troubleshooting bundle job

Cancels an in-progress troubleshooting bundle job by specifying the job name along with the required authentication details.

Requests
Path Parameters
jobName
string Required
Request Body
jobName
string Required

The unique identifier of the troubleshooting bundle job to cancel.

productName
string Required

The name of the product for which the troubleshooting bundle was created.

serviceId
string Required

The unique identifier of the service associated with the troubleshooting bundle.

bundleDest
string Required

Destination path or identifier for the troubleshooting bundle (typically “NETWORK”).

filepath
string Required

The file path where the troubleshooting bundle is being stored.

username
string Required

The username for authentication with the destination server.

password
string Required

The password for authentication with the destination server.

logLevel
string Required

The log level used for the troubleshooting bundle. Values: “defaultNodeLogs”, “defaultLogsAndMdmInfo”, “latestLogs”.

downloadFileKey
string Required

The unique identifier key for the download file.

selectedNodeList
array[object]

The list of nodes included in the bundle when node selection was ‘SELECTED’.

id
string Required

Unique identifier of the node

name
string Required

Display name of the node

ipAddress
string Required

IP address of the node

checked
string Required

Flag indicating whether the node is selected for inclusion

includeEsxiLogs
boolean Required

This flag indicating whether ESXi logs should be included in the bundle.

cloudLinkLogs
boolean Required

This flag indicating whether Cloud Link logs should be included in the bundle.

includeOldPodLogs
boolean Required

This flag indicating whether old pod logs should be included in the bundle.

iDracLogs
boolean Required

This flag indicating whether iDRAC logs should be included in the bundle.

mgmtPlatformLogs
boolean Required

This flag indicating whether management platform logs should be included in the bundle.

powerflexBlockLogs
boolean Required

This flag indicating whether PowerFlex block logs should be included in the bundle.

switchLogs
boolean Required

This flag indicating whether switch logs should be included in the bundle.

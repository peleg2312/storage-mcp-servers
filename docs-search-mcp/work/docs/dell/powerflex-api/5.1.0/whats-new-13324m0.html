What is new in the PowerFlex Block API (erasure coding)

The following API endpoints were added or deprecated in the PowerFlex Block API (Erasure Coding):

Added the following endpoint:

Endpoint Functionality
/api/v1/storagenode/modify Modify properties of a single storage node.

Deprecated the following endpoints:

Endpoint Functionality
/api/instances/StoragePool::{id}/action/renameStoragePool Rename a storage pool.
/api/instances/StoragePool::{id}/action/removeStoragePool Delete a storage pool.
/api/instances/ProtectionDomain::{id}/action/setRfcacheParameters Set RFcache parameters for a specified protection domain.

Deprecated the following endpoints for the installer API:

Endpoint Functionality
/api/types/Esrs/actions/register Get your endpoint for ESRS, and register to the ESRS server
/api/types/Esrs/actions/unregister Unregister from the ESRS server
/api/types/Esrs/actions/remove Unregister from the ESRS server and remove the certificate
/api/types/Esrs/actions/checkConnection Check the ESRS gateway connection
/api/types/Esrs/actions/setConnectInIp Add a ConnectIn IP to a registered system
/api/types/Esrs/actions/start Start passing alerts to ESRS gateway
/api/types/Esrs/actions/stop Stop passing alerts to ESRS gateway
/im/types/Configuration/actions/liaAddLdapService Add a LIA LDAP server
/im/types/Configuration/actions/liaDeleteLdapService Remove a LIA LDAP server
/im/types/Configuration/actions/liaSetAuthenticationMethod Set the LIA LDAP mode
/im/types/Configuration/actions/liaReadLdapConfiguration Read the LIA LDAP configuration

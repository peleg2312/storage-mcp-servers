Erasure coding APIS > PowerFlex Manager (AsmManager) REST API > Troubleshooting Bundle

Export troubleshooting bundle

Sends the troubleshooting bundle to the specified destination. This can be performed by an admin or a read-only user.

Requests
Request Body
productName
string Required

The name of the product for which the troubleshooting bundle is being exported.

serviceId
string Required
bundleDes
string Required

NOTE: The value is NETWORK.

filepath
string Required

NOTE: Multiple backslashes in the path is a known behavior. No changes are required.

username
string Required
password
string Required
includeSDNASLogs
string Required

The flag indicating whether SDNAS logs should be included in the bundle.

logLevel
string Required

The log level to be used for the troubleshooting bundle. For example, INFO, DEBUG, ERROR.

nodeSelection
string Required

The method of node selection for the bundle. For example, ALL, SELECTED.

selectedNodeList
array[object]

The list of nodes to include in the bundle when nodeSelection is ‘SELECTED’.

id
string Required

The unique identifier of the node.

name
string Required

The display name of the node.

ipAddress
string Required

The IP address of the node.

checked
string Required

The flag indicating whether the node is selected for inclusion.

downloadFileKey
string Required

The unique identifier key for the download file.

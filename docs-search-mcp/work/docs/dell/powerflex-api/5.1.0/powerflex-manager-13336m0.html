Introduction

Introduction to PowerFlex Manager

PowerFlex Manager provides IT operations management for Dell PowerFlex rack and appliance. It
increases efficiency by reducing time-consuming manual tasks that are required to manage system operations. Use PowerFlex Manager to deploy and manage new and existing environments.

PowerFlex Manager is distributed as a virtual appliance running a collection of interacting web applications that communicate
through the REST interfaces. An extra web application, the PowerFlex Manager UI, also resides on the virtual appliance,
providing full browser-based GUI access to PowerFlex Manager. This PowerFlex Manager UI interacts with PowerFlex
Manager through the same REST interfaces that are described in this guide.
If you have a licensed version of PowerFlex Manager, PowerFlex Manager can be integrated with any custom UI or accessed
through programs for an enhanced automation experience.

PowerFlex Manager API

PowerFlex Manager is a REST API. This API allows you to integrate PowerFlex Manager with any custom UI
or access it through programs for an enhanced automation experience. It is assumed that you are
familiar with REST, and programmatic interaction with REST APIs.

This guide describes how to use these APIs with examples.
It is assumed that you are familiar with REST, and programmatic interaction with REST APIs.

Target audience

The target audience for the PowerFlex Manager API includes programmers responsible for integrating third-party software with PowerFlex
Manager.

Basic concepts

PowerFlex Manager includes the following features:

  • A dashboard that provides system configuration details and communicates health status for infrastructure elements and services
  • Firmware and software compliance monitoring and reporting
  • Compliance remediation for nodes, switches, VMware ESXi, PowerFlex, and CloudLink
  • Hardware monitoring and alerting through either secure connect gateway, email, or SNMP and syslog to Dell Technologies Support
  • Aggregated logging for troubleshooting with the ability to send logs through secure connect gateway to Dell Technologies Support
    Use PowerFlex Manager to define and capture infrastructure requirements to support a specific business outcome. Once
    defined, the process can be repeated through automation.

Most of the REST methods in the PowerFlex Manager API exchange complex data models within the HTTP requests and responses.
These data models are represented as either XML or JSON.

Two essential concepts in PowerFlex Manager are the ServiceTemplate and the Deployment process. A ServiceTemplate
describes a blueprint for provisioning and configuring a collection of devices as a named unit, also known as a Service. The
Deployment process uses a ServiceTemplate to physically realize what service the service template describes. While the names
Deployment and Service are synonymous, PowerFlex Manager uses the term Service, whereas the REST API uses the term
Deployment.

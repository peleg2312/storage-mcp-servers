Adding a new credential

You can add a new credential by calling this API:

POST /Credential

This API only supports XML for request payloads. Both JSON and XML are supported for response payloads.

Sample request body:

<?xml version="1.0"?>
<asmCredential>
  <serverCredential>
    <label>AER Server</label>
    <username>root</username>
    <password>calvin</password>
  </serverCredential>
</asmCredential>

Pausing an inventory job

You can pause inventory jobs before an upgrade to prevent upgrade failure.

1. Get the list of all inventory job IDs required for the pause API call

curl -X 'GET' \
  'https://<powerflex_manager_hostname>/Api/V1/JobManager?filter=eq%2Cjobtype%2Cinventory&limit=50&offset=0' \
  -H 'accept: application/json' \
  -H 'Authorization: Bearer <token>'

2. Pause the inventory job

curl -X 'POST' \
  'https://<powerflex_manager_hostname>/Api/V1/JobManager/Job-2a065db5-a695-4a1c-8553-b114370cd559/pause' \
  -H 'accept: application/xml' \
  -H 'Authorization: Bearer <token>' \
  -H 'Content-Type: application/json' \
  -d '{
  "paused": true
}'

3. Resume the inventory job

curl -X 'POST' \
  'https://<powerflex_manager_hostname>/Api/V1/JobManager/Job-2a065db5-a695-4a1c-8553-b114370cd559/pause' \
  -H 'accept: application/xml' \
  -H 'Authorization: Bearer <token>' \
  -H 'Content-Type: application/json' \
  -d '{
  "paused": false
}'

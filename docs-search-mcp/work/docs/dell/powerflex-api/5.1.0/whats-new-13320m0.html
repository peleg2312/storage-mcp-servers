What is new in the PowerFlex Power API

In PowerFlex 5.1, the new dynamic licensing API endpoints have been added for smoother license activation across the PowerFlex systems. The following API endpoints were added or modified in the PowerFlex Power API:

Added the following endpoints:

Endpoint Functionality
/licenses Retrieves license information
/licenses-config Retrieves license configurations
/licenses-config/register-connected-licensing Sets up Dell Dynamic Licensing during initial setup
/licenses-config/update-offline-licensing Upload and replace an existing licensing file
/licenses-config/{id} Accept or decline EULA for license configurations

Modified the following endpoint:

Endpoint Modification
/dispatch-destinations/ Two new attributes, deploymentType and licenseType have been added for destination type SUPPORTASSIST.

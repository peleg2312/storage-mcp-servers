Modify storage node

This endpoint allows you to modify one or more properties of a single storage node in a single request. For example, you can rename the storage node, add or remove ip, or change the role.

Requests
Request Body
snModifyObject
object

Storage node modify object.

nodeId
string Required

The ID of the Storage Node to modify.

storageNodeName
string Required

The name of the Storage Node to modify.

ip
string Required

The IP address of the Storage Node to modify.

role
string Required

The current role of the Storage Node.

newRole
string Required

The new role to assign to the Storage Node.

Responses
200 : OK
Successfully modified all changes of SN.
400 : Bad Request
Invalid JSON.
500 : Server Error
Handler or orchestrator failure.
POST
/api/v1/storagenode/modify
/api/v1/storagenode/modify

Query system instances

Retrieves a list of system objects.

Responses
200 : OK

OK

Response Body
Array Of:
array[object]
numOfProtectionDomains
string

A list of protection domain IDs.

numOfStorageNode
number

The number of storage nodes.

numOfPds
number

The number of protecton domains.

numOfDgwt
number

The number of device gateway targets.

Sdtids
string

A list of SDT IDs.

numOfLibsdc
number

The number of library SDCs present in the system.

sdcIds
number

A list of SDC IDs.

numOfStoragePools
number

The number of storage pools.

numOfDeviceGroup
number

The number of device groups.

numDgsRebuildInProgress
number

The number of device groups that are undergoing a rebuild operation.

numOfDevices
number

The number od devices.

deviceIds
string

A list of device IDs.

numDevErrors
number

The number of device errors in the system.

numSmartAttributesPassedThreshold
number

The number of smart attributes that have passed a certain threshold. A smart attribute relatees to the health and performance of devices in the system.

numOfVtrees
number

The number of vTrees.

numOfVolumes
number

The number of volumes.

numOfUserVolumes
number

The number of volumes that are used by users

numOfMappedToAllVolumes
number

The number of volumes that are currently exposed to all SDCs or NVMe nodes in the system.

numOfUnmappedVolumes
string

The number of volumes that are not currently mapped to any SDCs or NVMe nodes.

numOfVolumesInDeletion
number

The number of volumes that are being deleted.

numOfSnapshots
number

The number of snapshots.

numSnapshotsTaken
number

The number of snapshots taken.

numOfSnapPolicies
number

The number of snpashot policies.

snapPolicyIds
number

A list of snapshot policy IDs.

numPdsSdcDisconnections
number

The number of disconnections between protection domains and SDCs.

numPdsSdtDisconnections
number

The number of protection domain to SDT disconnections.

numOfHostGroup
number

The number of host groups.

hostGroupIds
string

A list of host group IDs.

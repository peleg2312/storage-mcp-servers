Retrieve delta for storage pool

Returns changes in storage pools since the last call of this query.

To begin querying deltas, use sessionTag=0 and lastVersion=0.

For subsequent queries, use values returned by the previous query.

Response Body
StoragePool_Delta
object
sessionTag
number

Session for communicating delta changes with MDM; echoed back in the next call. Use 0 for the first call.

lastStoragePoolVersion
number

Identifier for the next call within the session; use 0 for the first call.

isDirty
boolean

Indicates data changed during request processing; changes may not appear in the response, so an extra query might be needed to catch missed updates.

storagePoolIsPartial
boolean

Indicates only partial data was returned because the response exceeded the MDM size limit; remaining data must be fetched with another query using sessionTag and lastStoragePoolVersion.

storagePoolList
array[object]

List of StoragePool objects added or modified since the last query. If the response is full (deletedStoragePoolIdList = null), it includes all existing StoragePools—unless storagePoolIsPartial = true, in which case it’s only a subset.

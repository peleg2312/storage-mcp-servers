Erasure coding APIS > PowerFlex Manager (AsmManager) REST API > Troubleshooting Bundle

Retrieve troubleshooting bundle status

Retrieves the current status of a troubleshooting bundle creation process.

Requests
Request Body
bundleDest
string Required

The destination path or identifier where the troubleshooting bundle is being created.

Responses
204

No Content

Response Body
id
string Required

The unique identifier of the troubleshooting bundle job.

filepath
string Required

The file path where the troubleshooting bundle is being stored.

username
string Required

The username associated with the bundle creation request.

generationDate
string Required

The timestamp when the troubleshooting bundle was generated.

bundleDest
string Required

The destination path or identifier for the troubleshooting bundle.

downloadUrl
string Required

The URL from which the troubleshooting bundle can be downloaded.

status
string Required

The current status of the bundle creation. For example, IN_PROGRESS, COMPLETED, FAILED.

statusMessage
string Required

The detailed message describing the current status or any errors encountered.

POST
/Troubleshootingbundle/status
/Troubleshootingbundle/status

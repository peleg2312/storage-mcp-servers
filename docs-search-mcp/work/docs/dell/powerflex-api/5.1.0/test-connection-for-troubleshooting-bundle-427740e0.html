Erasure coding APIS > PowerFlex Manager (AsmManager) REST API > Troubleshooting Bundle

Test connection for troubleshooting bundle

Tests the connection to the destination before exporting a troubleshooting bundle. This can be performed by admin or read-only users.

Requests
Request Body
productName
string Required

The name of the product

serviceId
string
bundleDes
string

NOTE: The value is NETWORK.

filepath
string

NOTE: Multiple backslashes in the path is a known behavior. No changes are required.

username
string
password
string Required
includeSDNASLogs
string Required

Flag indicating whether SDNAS logs should be included in the bundle

logLevel
string Required

The log level to be used for the troubleshooting bundle. For example, INFO, DEBUG, ERROR

nodeSelection
string Required

The method of node selection for the bundle. For example, ALL, SELECTED

selectedNodeList
array[object]

List of nodes to include in the bundle

id
string Required

Unique identifier of the node

name
string Required

Display name of the node

ipAddress
string Required

IP address of the node

checked
string Required

Flag indicating whether the node is selected for inclusion

downloadFileKey
string Required

Unique identifier key for the download file

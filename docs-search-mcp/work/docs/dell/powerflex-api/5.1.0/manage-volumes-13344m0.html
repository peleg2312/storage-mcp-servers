Volume management

Create a thin volume

This example shows how to create a new 128GB thin, uncompressed, volume named asmdata in FG pool sp2:

curl -v -k -r POST -u <user>:<token> -H "Content-Type: application/json" 'https://<PowerFlex-GW-IP>/api/types/Volume/instances' --d '
{
  "name": "asmdata",
  "compressionMethod": "None",
  "storagePoolId": "fe9ddde400000001",
  "volumeType": "ThinProvisioned",
  "volumeSizeInGb": "128"
}'

The 200 response contains the internal identifier (volume ID) for the volume asmdata:

{
  "id":"dcf7b37a00000056"
}

Map the volume to an SDC

To map the volume to an SDC, first use the volume ID created in the previous step and the IP address of the SDC you want to map the volume to in order to retrieve the SDC ID. The following command returns the ID of the SDC when supplied the IP address of the SDC:

curl -v -k -r POST -u <user>:<token> -H "Content-Type: application/json" 'https://<PowerFlex-GW-IP/api/types/Sdc/instances/action/queryIdByKey' -d '
{
  "ip": "172.17.161.56"
}'

The 200 response contains the ID of the SDC:

{
  "id":"dbb1e85d0000000e"
}

Use the volume ID (as a URI path parameter) and the SDC ID from the previous steps to map the volume to an SDC:

curl -v -k -r POST -u <admin>:<token> -H "Content-Type: application/json" 'https://<PowerFlex-GW-IP>/api/instances/Volume::dcf7b37a00000056/action/addMappedSdc' -d '
{
  "sdcId": "dbb1e85d0000000e"
}'

The 200 response is empty:

{}

Map the same volume to a second SDC

To map the volume created in the previous step to a second SDC, first allow the volume to be mapped to multiple SDCs:

curl -v -k -r POST -u <user>:<token> -H "Content-Type: application/json" 'https://<PowerFlex-GW-IP>/api/instances/Volume::dcf7b37a00000056/action/addMappedSdc' -d '
{
  "sdcId": "dbb1732d00000002",
  "allowMultipleMappings": "TRUE"
}'

The 200 response is empty:

{}

Expand a mapped volume

To expand the volume from 128Gb to 256GB:

curl -v -k -r POST -u <user>:<token> -H "Content-Type: application/json" 'https://<PowerFlex-GW-IP>/api/instances/Volume::dcf7b37a00000056/action/setVolumeSize' -d '
{
  "sizeInGB": "256"
}'

The 200 response is empty:

{}

Remove volume mapping

To remove mapping of volume “asmdata” from SDC ID “dbb1732d00000002”:

curl -v -k -r POST -u <user>:<token> -H "Content-Type: application/json" 'https://<PowerFlex-GW-IP>/api/instances/Volume::dcf7b37a00000056/action/removeMappedSdc' -d '
{
  "sdcId": "dbb1732d00000002"
}'

The 200 response is empty:

{}

Create snapshot of a volume

To create a read-only snapshot of volume “asmdata”:

curl -v -k -r POST -u <user>:<token> -H "Content-Type: application/json" 'https://<PowerFlex-GW-IP>/api/instances/System::6870804f36d7120f/action/snapshotVolumes' -d '
{
  "snapshotDefs": [
    {
      "volumeId": "dcf7b37a00000056",
      "snapshotName": "asmdata_snap1"
    }
  ],
  "accessModeLimit": "ReadOnly"}'

The 200 response includes the snapshot group ID and the volume ID of the snapshot:

{
  "snapshotGroupId":"ff1940a600000001",
  "volumeIdList":
    ["dcf7b3880000001c"]
}

Lock a snapshot

To lock a snapshot:

curl -v -k -r POST -u <user>:<token> 'https://<PowerFlex-GW-IP>/api/instances/Volume::dcf7b3880000001c/action/lockAutoSnapshot’  -d '
{
  "autoSnapshotWillBeRemoved": "false"
}'

The 200 response is empty:

{}

Unlock a snapshot

To unlock a snapshot:

curl -v -k -r POST -u <user>:<token> 'https://<PowerFlex-GW-IP>/api/instances/Volume::dcf7b3880000001c/action/unlockAutoSnapshot' -d '
{
  "autoSnapshotWillBeRemoved": "false"
}'

The 200 response is empty:

{}

Retrieve volume information

curl -v -k --request GET -u <user>:<token> 'https://<PowerFlex-GW-IP>/api/instances/Volume:: dcf7b37a00000056’

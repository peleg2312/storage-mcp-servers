Error messages

Two possible error messages can be returned when the REST API command contains an error:

Simple error message

A simple error messages contain the following fields:

  • Error code
  • Http status code
  • Message

Example:

{
    "errorCode": 0,
    "httpStatusCode": 400,
    "message": "Request validation Error. Got illegal parameter: accessMode"
}

Detailed error message

A detailed error messages contain the following fields:

  • Message
  • Http status code
  • Error code
  • Details:
    • error message
    • error
    • rc
    • info

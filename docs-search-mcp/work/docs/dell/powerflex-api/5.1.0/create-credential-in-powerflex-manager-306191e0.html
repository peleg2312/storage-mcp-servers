Create credential in PowerFlex Manager

Creates a credential in PowerFlex Manager.

Requests
Request Body
credential
object

Node (IDRAC), Switch, or OS credential

id
string

Ignored on POST will be assigned in POST response, from Powerflex Manager

type
object

Type of credential

allowed values: NODE OS SWITCH
name
string

Name (label) in Powerflex Manager

username
string
password
string
snmptype
object

SNMP version. Used when “type=NODE|SWITCH”, possible values v2 or v3

allowed values: V2 V3
snmpv2community
string

Community string for SNMPv2

snmpv3user
string

Username for SNMPv3

snmp3level
object

User security level

allowed values: MINIMAL MODERATE MAXIMUM
authenticationType
object

Authentication type for SNMPv3 users

allowed values: MD5 SHA HMAC128SHA224 HMAC192SHA256 HMAC256SHA384 HMAC384SHA512
authenticationPassword
string

Authentication password for SNMPv3 users

desPrivacyPassword
string

Used when “type=NODE”, “snmptype=V3”, and SNMPv3 level is MAXIMUM

domain
string

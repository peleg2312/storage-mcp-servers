Erasure coding APIS > PowerFlex Block REST API > Metrics

Query capacity and performance metrics

Retrieves metrics for a specified resource type.

Requests
Query Parameters
filter
string
Request Body
resource_type
string Required

The type of resource for which to retrieve metrics.

ids
string

The ID of the object for which to retrieve metrics.

metrics
string

A list of specific metrics to retrieve, separated by commas.

Responses
200 : OK

OK

Response Body

resourceType
object Required
allowed values: Volume System Device Protection Domain VTree SDC Storage Node Device Group SDT Storage Pool

avg_fe_trim_io_size
integer

Measures the average size of TRIM I/O operations handled at the front-end interface during the observation period.

compression_ratio
integer

Measures the average time taken to complete read I/O operations on PMEM devices that belong to a specific volume group.

physical_used
integer

The physical capacity used by user data in the system.

integer

Measures how effective snapshots are in reducing storage consumption. A higher ratio means more space savings because snapshots reuse existing blocks instead of creating full copies.

physical_free
integer

The amount of physical storage space currently available (unused) on the system, after accounting for: Data stored, system overhead and data reduction effects.

host_trim_bandwidth

A configuration that limits or reduces the bandwidth available to a specific host on a network.

host_trim_iops
integer

The number of I/O operations per second associated with TRIM commands issued by a host to a storage device.

physical_total
integer

The total amount of physical memory (RAM) installed in a system.

reducible_ratio

Erasure coding APIS > PowerFlex Block REST API > Device Gateway Target

Retrieve delta for device gateway target

Returns changes in the device gateway targets since the last call of this query.

To begin querying deltas, use sessionTag=0 and lastVersion=0.

For subsequent queries, use values returned by the previous query.

Requests
Query Parameters
system id
string Required
sessionTag
string Required

A session in which communication with the MDM about the delta occurs. The delta is echoed back to the MDM in the subsequent call within the same session. Use 0 for the initial call.

lastDgwtVersion
string Required

Identifier within the session to be used in the next call. Use 0 in the initial call.

isDirty
string Required

“True” means data changed during request processing. These changes might not appear in the response, so depending on the use-case, an extra query may be needed to catch missed updates.

DgwtIsPartial
boolean Required

“True” means only partial data was returned because the response exceeded MDM’s size limit. To retrieve the remaining data, send another query using the provided sessionTag and lastDgwtVersion.,

DgwtList
boolean Required

A list of added or modified device gateway target objects since the last query. If deletedHostGroupIdList is null, the response includes all existing Host Groups—unless hostGroupIsPartial = true, in which case the list is only a subset.

deletedDgwtIdList
boolean Required

A list of IDs for deleted device gateway target objects since the last query. If the list is null, the response includes all current device gateway targets, and any missing ones should be considered deleted. If systemNetworkIsPartial is also set, deletions should only be confirmed after receiving a complete response. This is important for use-cases sensitive to delete-and-recreate bursts.

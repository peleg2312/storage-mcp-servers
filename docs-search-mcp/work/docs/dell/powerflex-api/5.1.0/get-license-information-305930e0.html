Common APIs for Erasure Coding and Mirroring > PowerFlex Licensing REST API > licenses

Get license information

Retrieves license information for the connected PowerFlex systems.

Responses
200 : OK

OK

Response Body
LicensesCollection
object

A collection of licenses instance. It’s an array of three elements. The first element is for mirroring (we only need to return the first element for mirroring), and all three elements are used for EC.

results
array[object]
id
string

Unique identifier of a licenses resource. for a singleton system, return 0.

is_licensed
boolean

When false, this license has never been active on this product instance.

is_active
boolean

When is_licensed is true, and expiration_time is either not applicable
for the expiration_type or in the future, the license is currently active.

The license is considered active if the is_licensed status is true and the expiration_time is either not applicable based on the expiration_type or has a future date.

name
string

The name of the feature codes.

type
string

The various types of licenses are:

  • RELEASE - Base software and included features.
  • FEATURE - Name should include tier or feature name.
  • CAPACITY - Name should include metered resource, currently only storage.
  • SUPPORT - Support contract - entitled, but not licensed.
  • SERVED_FEATURE - Licenses are drawn from license server pool of license counts.
  • SERVED_CAPACITY - Licenses are drawn from a license server pool of license capacity.

For PowerFlex systems, the value will always be SERVED_CAPACITY.

allowed values: RELEASE FEATURE CAPACITY SUPPORT SERVED_FEATURE SERVED_CAPACITY
expiration_type
string

The various types of license duration or expiration are:

  • TRIAL - A short term license to use sample functionality.
  • EXT_TRIAL - A one-time extension to an existing trial license.
  • TIME_LIMITED - A license with an expiration time.
  • GRACE_PERIOD - A time limited license that allows a short period of continued use after expiration.
  • RESTRICTED - A time limited license that restricts functionality after expiration. After expiration, you can still use existing configurations, but provisioning new systems won’t be possible.
  • PERMANENT - A non-expiring license.
allowed values: TRIAL EXT_TRIAL TIME_LIMITED GRACE_PERIOD RESTRICTED PERMANENT
expiration_time
string<date-time>

The time at which the license expires. This is only applicable for TRIAL, EXT_TRIAL, TIME_LIMITED, or RESTRICTED types of license-expiration.

grace_expiration_time
string<date-time>

The time at which a license’s grace period expires. This is only applicable for the GRACE_PERIOD type of license-expiration.

capacity
integer<int64>

The limit on the license. This is only applicable for CAPACITY, SERVED_CAPACITY, or SERVED_FEATURE license types.

capacity_units
string

Valid values of license capacity_units attribute.

  • COUNT - A specific quantity limit.
  • PERCENT - A percentage value in the 0-100 range.
  • REQUEST_P_MIN - Requests per minute.
  • BYTE - Bytes of data.
  • BYTE_P_SEC- Bytes per second of throughput.
  • IO_P_SEC - IOs per second of throughput.

For PowerFlex, the return value is BYTE.

allowed values: COUNT PERCENT REQUEST_P_MIN BYTE BYTE_P_SEC IO_P_SEC
served_capacity_used_all
integer<int64>

For SERVED_CAPACITY and SERVED_FEATURE types of licenses, this reports the total capacity being used by all systems consuming from the pool.

served_capacity_used_system
integer<int64>

For CAPACITY and SERVED_CAPACITY types of licenses, this reports how much of the capacity is being used by the local system.

capacity_enforcement_status
string

The compliance level or status of the license. The possible levels and their descriptions are listed below:

  • OK - Consumption is under 90% of capacity limit, and expiration is over 60 days away.
  • INFO - For future use to show information about licensing state that is not near expiration or consumption limit.
  • WARNING - The used raw capacity is over 90% and/or expiration is less than 60 days away.
  • ALERT - The used raw capacity is over 95% and/or expiration is less than 15 days away. Take action to adjust usage, licensed capacity, or expiration as soon as possible.
  • CRITICAL - The system has exceeded the licensed capacity limit or license expired. Data can still be accessed but configuration changes are blocked. Take action to adjust usage, licensed capacity, or expiration as soon as possible.
allowed values: OK INFO WARNING ALERT CRITICAL

Introduction

Introduction to PowerFlex (mirroring)

PowerFlex is an enterprise-class, software-defined block storage solution that is deployed, managed, and supported as a single system. Highly flexible and scalable, PowerFlex allows customers to mix two-layer (Server SAN), single-layer, and storage-only and mixed architectures within a single deployment.

PowerFlex Block API

The PowerFlex Block API is installed as part of the PowerFlex installation manager/PowerFlex gateway package. The installation manager manages deployment and upgrades. The PowerFlex gateway leverages role-based security access to expose RESTful APIs for automating all frontend and backend storage tasks and core components, and also acts as a gateway for SNMP traps and secure remote services.

The REST API is served from the PowerFlex gateway through the REST gateway. The PowerFlex Gateway connects to a single MDM (metadata manager) and serves requests by querying the MDM and reformatting the answers it receives from the MDM in a RESTful manner back to a REST client.

Every PowerFlex SCLI command is also available in the PowerFlex REST API. The responses returned by the PowerFlex gateway are in JSON format.

APIs may change as new features are added to the product or changes are made to the PowerFlex software.

Target audience

The PowerFlex Block API is intended for customers who want to automate PowerFlex deployment, configuration, and management tasks.

Basic concepts

The following basic concepts are relevant to understanding and operating PowerFlex.

Concept Description
Acceleration pool An accleration pool is a group of one or more physical acceleration devices.
Fault set A fault set is a logical entity that contains a group of SDSs that are more inclined to go offline simultaneously.
Meta Data Manager A Meta Data Manager (MDM) configures and monitors PowerFlex, and is usually configured in redundant cluster mode to support high availability.
Protection domain A protection domain is a logical entity that consists of a group of storage data servers (SDSs) that backs up each other
Snapshot A snapshot is an image-level view of data at a particular point in time.
Storage data client A storage data client (SDC) is a lightweight device driver that exposes PowerFlex volumes as block devices to the application that resides on the same server on which the SDC is install.
Storage data replicator A storage data replicator (SDR) is a tool, which processes the application I/Os of the source SDRs.
Storage data server A storage data server (SDS) manages the capacity of a single server and acts as a backend for data access.
Storage pool A storage pool is a set of physical storage devices in a protection domain. A volume is distributed over the devices residing in the same storage pool.
Volume A volume consists of multiple storage blocks spread evenly across devices.

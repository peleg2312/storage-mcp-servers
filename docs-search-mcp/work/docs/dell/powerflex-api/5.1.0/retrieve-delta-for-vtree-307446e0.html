Retrieve delta for VTree

Returns changes in VTrees since the last call of this query.

To begin querying deltas, use sessionTag=0 and lastVersion=0.

For subsequent queries, use values returned by the previous query.

Requests
Query Parameters
system id
string Required
session tag
string Required
Responses
200 : OK

OK

Response Body
VTree_Delta
object

An object that contains data regarding the changes that occurred in VTree objects in the cluster since the last request, and data regarding how to send the next query.

sessionTag
string

The session in which communication with the MDM regarding the delta is done. It is echoed back to the MDM in the next call within this session. Use 0 for the initial call.

isDirty
boolean

TRUE indicates that changes to the data queried occurred during the processing of the request. These changes may or may not be reflected in the response. Depending on the use case, sending an additional query to check for missed changes may be advisable.

lastVTreeVersion
number

Identifier within the session to be used in the next call. Use 0 in the initial call.

vTreeIsPartial
boolean

TRUE indicates that only partial data was sent due to the response size passing the threshold defined in MDM. The remaining data should be retrieved using another query with the sessionTag + lastVTreeVersion values returned by this query.

vTreeList
array[object]

List of added or modified VTree objects since the last query. In case of a full response (deletedVTreeIdList = null), this list contains all the VTree objects that currently exist (unless vTreeIsPartial = true, in which case this list is a subset of all currently existing VTree objects).

numOfVolumes
number
vtreeDeletionProgress
number
volumesTotalDeletionProgress
number
deletedVTreeIdList
array[string]

List of IDs of deleted VTree objects since the last query. If the list is null (unlike an empty list), it means that the response contains all instances of VTree objects; any VTree objects not included in this response should be considered as deleted.
NOTE: This attribute may be set in conjunction with the vTreeIsPartial attribute, in which case only VTree objects that are not present in this response and any of the subsequent responses until a non-partial response was received were actually deleted. If your use-case is sensitive to bursts of delete-and-re-create events, this should be taken into account.

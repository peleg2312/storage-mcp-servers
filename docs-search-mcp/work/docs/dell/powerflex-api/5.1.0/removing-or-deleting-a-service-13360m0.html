Removing or deleting a service

You can remove a service (called a resource group in the UI) that is no longer required. PowerFlex Manager supports two types of removal:

  • Delete the entire service, which deletes the deployment information and also makes any required configuration
    changes for components that are associated with the service.
  • Remove just the deployment information for the service without making any configuration changes to the deployed
    components.

To remove a service, simply call the following API:

DELETE /Api/V1/Deployment/{id}

To delete a service, perform these steps:

  1. Retrieve the Deployment object.
  2. Set teardown = true on the Deployment object.
  3. For each component (deployment.serviceTemplate.components[]) that you want to have delete / teardown options run on, set teardown = true, and within each of those components’ resources, set the ensure parameter to absent.

Setting the component teardown options is equivalent to selecting the checkboxes shown in the Delete Service wizard. Note that the UI forces you to “teardown” the node components, whereas in the API this is optional. You must specify the teardown options for the components, as described above.

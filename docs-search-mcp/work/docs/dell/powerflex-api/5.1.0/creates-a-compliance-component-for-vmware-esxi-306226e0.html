Creates a compliance component for VMware ESXi

Creates a compliance component for a VMware ESXi hypervisor. Returns a Job ID.

Requests
Request Body
compType
string

The component type being targeted: a VMware ESXi hypervisor.

firmwarePackageId
string

A unique identifier for the firmware package to be applied.

isofilepath
string

The URL to the ISO image of the ESXi installer.

depotfilepath
string

The URL to the ESXi offline bundle (depot ZIP), which contains VIBs (VMware installation bundles) and metadata.

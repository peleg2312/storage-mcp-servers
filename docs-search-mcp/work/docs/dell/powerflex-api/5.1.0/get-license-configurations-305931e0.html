Common APIs for Erasure Coding and Mirroring > PowerFlex Licensing REST API > licenses-config

Get license configurations

Retrieves the license configuration for a connected PowerFlex system.

Responses
200 : OK

OK

Response Body
LicensesConfigCollection
object

A collection of license config.

results
array[object]
id
string

Unique identifier of a license configuration resource. Use “0” for a singleton resource.

swid
string

Identifier for the software instance.

locking_id
string

Locking ID value generated from system identifier(s) and used to securely identify system to Dell licensing service. It’s the installation_id

method
string

The various methods of supplying licenses to a system:

  • UNLICENSED - Prior to system initialization, the system will be unlicensed.
  • STATIC - Legacy licensing method using license files or license keys.
  • OFFLINE - Dynamic licensing, but through a licensing file generated and supplied by Dell.
  • DELL_CONNECTED - Dynamic licensing directly through the connected Dell licensing servers.
  • LOCAL_CONNECTED - Dynamic licensing through a connected licensing server present locally.
allowed values: UNLICENSED STATIC OFFLINE DELL_CONNECTED LOCAL_CONNECTED
reservation_pool_name
string

The reservation pool of which the current system is a member of. This is only applicable for connected dynamic licensing methods.

is_eula_accepted
boolean

If there is a End User License Agreement (EULA) associated with the system,
this flag signifies if that EULA has been accepted or not.

eula_text_l10n
string

A localized EULA message available which you can read before using the modify operation to
indicate acceptance. This can be the license text or an URL that leads to the license terms.

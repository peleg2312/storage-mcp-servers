Common APIs for Erasure Coding and Mirroring > PowerFlex Licensing REST API > licenses-config

Accept or decline End User License Agreement

This API allows you to accept or decline the End User License Agreement (EULA) for a specific license configuration.

Requests
Path Parameters
id
string Required

Unique identifier of the license configuration instance. For a singleton system, use id=0.

Request Body
LicensesConfigModify
object

Parameters of the licenses configuration modify operation.

is_eula_accepted
boolean

If there is a End User License Agreement (EULA) associated with the system, this flag indicates if that EULA has been accepted or declined.

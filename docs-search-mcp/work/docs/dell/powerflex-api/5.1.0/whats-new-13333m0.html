Getting Started > PowerFlex Block API (mirroring)

What’s new

The following endpoints are deprecated in the PowerFlex Block API (mirroring) for this release because the Read Flash Cache (RFcache) is deprecated:

Endpoint Functionality
/api/instances/ProtectionDomain::{id}/action/setRfcacheParameters Set RFcache parameters for a specified protection domain.
/api/instances/ProtectionDomain::{id}/action/enableSdsRfcache Enable RFcache in the speciifed protection domain.
/api/instances/ProtectionDomain::{id}/action/disableSdsRfcache Disable RFcache in the specified protection domain.
/api/instances/Sds::{id}/action/clearRfcacheError Clear RFcache errors on the specified SDS.
/api/instances/Sds::{id}/action/enableRfcache Enable RFcache on the specified SDS.
/api/instances/Sds::{id}/action/disableRfcach Disable RFcache on the specified SDS.

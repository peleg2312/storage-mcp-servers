Query all approved SDCs

Query the system when it is operating in restricted SDC mode for a list of all SDCs that have been approved by the system.

NOTE: This query is useful when restricted SDC mode is enabled and you want to determine which SDCs can be used for volume mapping.

List of approved SDC objects. See the SDC Objects table.

Get delta for PowerFlex data server

Returns changes in PowerFlex data servers since the last call of this query.

To begin querying deltas, use sessionTag=0 and lastVersion=0. For subsequent queries, use values returned by the previous query.

Requests
Query Parameters
lastPDSVersion
string Required

Identifier within the session to be used in the next call. Use 0 in the initial call.

sessionTag
string Required

A session involves communication with the MDM about changes (delta), which are echoed back in the next call within the same session. Use 0 for the initial call.

system id
string Required
Header Parameters
systemId
string
Responses
200 : OK

OK

Response Body
PDS_Delta
object

An object that contains data regarding the changes that occurred in the PowerFlex data servers in the cluster since the last request, and data regarding how to send the next query.

sessionTag
number

A session in which communication with the MDM regarding the delta is done. It is echoed back to the MDM in the next call within this session. Use 0 for the initial call.

lastPDSVersion
number

Identifier within the session to be used in the next call. Use 0 in the initial call.

isDirty
boolean

The option, “true”, means that changes to the data queried occurred during the processing of the request. These changes may or may not be reflected in the response. Depending on the use-case, sending an additional query to check for ‘missed’ changes may be advisable.

pdsIsPartial
boolean

The option, “true”, means only partial data was sent, due to the response size passing the threshold defined in MDM, and the remaining data should be fetched by another query using the sessionTag + lastPdsVersion values returned by this query.

PdsList
string

List of added / modified PowerFlex data server objects since the last query. In case of a full response (deletedHostGroupIdList = null) this list contains all the PowerFlex data servers that currently exist (unless hostGroupIsPartial = true, in which case this list is a subset of all currently existing PowerFlex data servers).

deletedPdsIdList
string

List of Ids of deleted PowerFlex data servers since the last query. If the list is null (unlike an empty list), it means the response contains all instances of PowerFlex data servers, and not the delta data, meaning any PowerFlex data servers not included in this response should be considered as deleted. This attribute may be set in conjunction with the systemNetworkIsPartial attribute, in which case only PowerFlex data servers that are not present in this response and any of the subsequent responses until a non-partial response was received were actually deleted. If your use-case is sensitive to bursts of delete-and-re-create events this should be considered.

Erasure coding APIS > PowerFlex Manager (AsmManager) REST API > nodepool

Retrieve filtered device group list

Retrieve a filtered list of device groups.

Requests
Query Parameters
filter
string

Search Operators: eq (equals), ne (not equal), ge (greater than equal), le (less than equal), gt (greater than), lt (less than), like, ilike, sw (starts with), ew (ends with), in, empty, notempty, null, notnull

Search Controls: and, or, not: (name like “CO-”) and (name not ew “-nodes”)

Searching for Strings should use " delimiter around the String. Searching for “in” should be a comma separated list of values.

Filtered result is supported on children- deviceInventories.

Example of parent level filter: (name eq “nodepool-1”)

Example of child level filter: (deviceInventories.ipAddress ne “10.125.148.25”)

sort
string

Supported sort columns are: name,createdBy,createdDate,updatedBy,updatedDate

offset
integer
default: 0

Specify pagination offset

limit
integer
default: 50

Specify page limit

Configure the PowerFlex Gateway using the REST API

If the PowerFlex Gateway was installed manually after PowerFlex was installed, use the following procedure to configure MDM connection properties and passwords in the PowerFlex Gateway. If the PowerFlex Gateway/PowerFlex Installer was used to install PowerFlex, the MDM connection properties are already configured, and you can skip this task.

  1. Invoke an HTTP GET request using the Gateway URI, followed by /api/gatewayLogin:
    https://<GATEWAY_IP_ADDRESS>/api/gatewayLogin

Example:

https://10.76.60.190:443/api/gatewayLogin
GET

  1. Log in as an admin user, using the gatewayAdminPassword. A token is returned.

  2. Set (POST) the MDM configuration:
    https://<server_ip>:443/api/updateConfiguration

with the following payload:

{
	"mdmAddresses":
		["<MDM_MANAGEMENT_IP_ADDRESS1>", "<MDM_MANAGEMENT_IP_ADDRESS2>"],
		"mdmPort":"<MDM_PORT>",
		"gatewayAdminPassword":"<ADMIN_PASSWORD>",
}

For example:
https://10.76.61.100:443/api/updateConfiguration

{
	"mdmAddresses":["10.76.61.32", "10.76.61.33"],
	"mdmPort":"6611",
	"gatewayAdminPassword":"123",
}

Configuration is complete.

NOTE:

For instructions on configuring the PowerFlex Gateway using cURL or manually editing the Gateway properties, see Additional Gateway configuration methods.]

gatewayAdminPassword

A number of requests require the gatewayAdminPassword instead of the admin password. These requests work similarly to requests requiring the MDM password, with the following exceptions:

  • Instead of /api/login, you should invoke an HTTP GET request, /api/gatewayLogin, with user: admin password: GATEWAY_ADMIN_PASSWORD in HTTP Basic authentication. A token is returned.

Example:

https://10.76.60.190:443/api/gatewayLogin
GET
  • Instead of invoking /api/logout, invoke /api/gatewayLogout with the token received when you logged in:

Example:

https://10.76.60.190:443/api/gatewayLogout
GET

Requests that require the gatewayAdminPassword are:

  • GET /api/Configuration
  • GET /api/gatewayLogout
  • GET /api/getHostCertificate/{Mdm | Lia}
  • POST /api/updateConfiguration
  • POST /api/instances/System/action/createMdmCluster
  • POST /api/trustHostCertificate/{Mdm | Lia}
  • POST /api/gatewaySetSecureCommunication

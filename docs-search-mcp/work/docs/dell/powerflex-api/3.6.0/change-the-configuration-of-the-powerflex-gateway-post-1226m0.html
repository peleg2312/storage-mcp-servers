Change the configuration of the PowerFlex Gateway (POST)

You can change the PowerFlex Gateway configuration at any time using the /api/updateConfiguration command:
https://<server_ip>:443/api/updateConfiguration

Note

This command requires the gatewayAdminPassword.

The request must contain one or more of the following parameters:

  • mdmAddresses: List of MDM IP addresses that the PowerFlex Gateway will use to connect to the MDM. For performance improvement, place the primary MDM IP addresses before the secondary ones).

  • mdmPort: MDM port

  • gatewayAdminPassword: Password for installation manager, getting/updating the PowerFlex Gateway configuration, and adding the primary MDM

  • systemId: ID of the system configured by mdmAddresses. If systemId is left empty, it will be populated on the first invocation of /api/login. At every /api/login, the system ID value is compared to the ID of the PowerFlex cluster (MDM). If the IDs are different ( mdmAddresses points to a cluster that does not match the systemId), an error message is displayed, and all login tokens (/api/login, /api/gatewayLogin) are invalidated. None of the PowerFlex Gateway clients will be able to send requests to the MDM until one of the following happens:

    • systemId is configured to the correct value
    • mdmAddresses is configured to the correct IP addresses
    • systemId is set to an empty value. In this case, on the first invocation of /api/login, the value for systemId will be populated according to the ID of the matching mdmAddresses.
      If the value for systemId is different from the configured systemId (and the configured systemId is not empty), all login tokens (/api/login, /api/gatewayLogin) are invalidated.

  • snmpSamplingFrequency: MDM sampling frequency in seconds. If sampling frequency is set to 0, the SNMP trap sender will be disabled, and no sampling to the MDM will be performed.

  • snmpResendFrequency: Resend frequency of SNMP traps, in minutes. If resend frequency is set to 0, all traps will be sent in every sampling.

  • snmpTrapsReceiverIp: SNMP trap receivers’ IP addresses (supports up to two comma-separated or semi-colon-separated IP addresses)

  • snmpPort: Port number used for SNMP traps

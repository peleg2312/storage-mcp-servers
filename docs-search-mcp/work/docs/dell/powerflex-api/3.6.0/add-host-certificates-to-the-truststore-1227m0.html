Add host certificates to the truststore

The truststore contains a list of the valid Certificate Authorities (CAs) that are trusted by the client machine for SSL server authentication. Use the following workflow to retrieve the MDM or LIA host’s certificates and add them to the truststore.

  1. Log in to the PowerFlex Gateway as an admin user, using the gatewayAdminPassword. A token is returned.

  2. Retrieve (GET) the MDM’s or LIA’s certificate:
    /api/getHostCertificate/{Mdm|Lia}?host={host ip}

Example:
/api/getHostCertificate/Mdm?host=10.76.60.10

  1. Save the entire certificate to a cer file.

  2. Save (POST) the certificate to the truststore:
    /api/trustHostCertificate/{Mdm|Lia}

The body of the request should contain a part named “file” and the file containing the certificate to be trusted.

Example:
/api/trustHostCertificate/Mdm

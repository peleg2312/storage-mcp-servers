SDC management

List the volumes mapped to an SDC

In order to list the volumes mapped to an SDC, you must first retrieve the SDC ID by querying the SDC IP address. In this example the IP address is 192.168.161.56.:

curl -k -r POST -u <user>:<token> -H "Content-Type: application/json" 'https://<PowerFlex-GW-IP>/api/types/Sdc/instances/action/queryIdByKey' -d '
{
  "ip":"192.168.161.56"
}'

The 200 response contains the SDC ID:

{
  "id":"dbb1e85c00000003"
}

Use the SDC ID from the previous step as the URI path parameter in the following query to list the details of each mapped volume for the SDC:

curl -k -r POST -u <user>:<token> 'https://<PowerFlex-GW-IP>/api/instances/Sdc::dbb1e85c00000003/relationships/Volume'

Remove an SDC

To remove an SDC from the PowerFlex system, you must first retrieve the SDC ID by running a query using its IP address. In this example the IP address is 172.17.161.130:

curl -k -r POST -u <user>:<token> -H "Content-Type: application/json" 'https://<PowerFlex-GW-IP>/api/types/Sdc/instances/action/queryIdByKey' -d '
{
  "ip":"172.17.161.130"
}'

The 200 response returns the SDC ID:

{
  "id":"dbb1e85b0000000e"
}

Check if volumes are mapped to the SDC

Before removing the SDC, verify there are no volumes mapped to the SDC:

curl -k -r GET -u <user>:<token> 'https://<PowerFlex-GW-IP> /api/instances/Sdc::dbb1e85b0000000e/relationships/Volume'

If the 200 response is empty, it is an indication that there are no volumes mapped to the SDC.

After stopping the SDC service, remove the SDC from the PowerFlex system:

curl -k -r POST -H "Content-Type: application/json" -u <user>:<token> 'https:// <PowerFlex-GW-IP> /api/instances/Sdc::dbb1e85b0000000e/action/removeSdc' -d '
{
  "id":"dbb1e85b0000000e"
}'

The 200 response is empty and the SDC is successfully removed:

{}

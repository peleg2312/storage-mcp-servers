Storage Pool Management

List volumes in a Storage Pool

To list the volumes in a Storage Pool, first retrieve the Storage Pool ID. In the following example, the Protection Domain name is “pd1” and the Storage Pool name is “sp1”:

curl -k -r POST -H "Content-type: application/json" -u <user>:<token> 'https://<PowerFlex-GW-IP>/api/types/StoragePool/instances/action/queryIdByKey' -d '
{
  "name":"sp1",
  "protectionDomainName":"pd1"
}'

The 200 response returns the Storage Pool ID:

{
  "id":“17a4946800000000”
}

Expand a Storage Pool by adding a device

Before expanding a Storage Pool by adding a device, first obtain the Storage Pool ID and the SDS ID. The Storage Pool ID and SDS ID are then passed as json strings when adding the device. In this example, device “/dev/sda” is added to SDS “sds3”, Storage Pool “mg-pool’ in Protection Domain “pd1”.

Retrieve the Storage Pool ID

Use the name of the storage Pool (mg-pool) and Protection Domain (pd1) to retrieve the Storage Pool ID:

curl -k -r POST -H "Content-type: application/json" -u <user>:<token> 'https:// ://<PowerFlex-GW-IP>/api/types/StoragePool/instances/action/queryIdByKey' -d '
{
  "name":"mg-pool",
  "protectionDomainName":"pd1"
}'

The 200 response contains the Storage Pool ID:

{
  "id":"1d22fd3a00000000"
}

Retrieve the SDS ID

Use the name of the SDS (sds3) to query the ID of the SDS:

curl -k -r POST -H "Content-type: application/json" -u <user>:<token> 'https:// ://<PowerFlex-GW-IP>/api/types/Sds/instances/action/queryIdByKey' -d '
{
  "name":"sds3"
}'

The 200 response contains the SDS ID:

{
  "id":"271739dc00000000"
}

Add a device to the Storage Pool

Add the new device in sds3 to Storage Pool mg-pool in Protection Domain pd1:

curl -k -r POST -H "Content-type: application/json" -u <user>:<token> 'https:// ://<PowerFlex-GW-IP>/api/types/Device/instances' -d '
{
  "sdsId":"271739dc00000000",
  "storagePoolId":"1d22fd3a00000000",
  "deviceCurrentPathname":"/dev/sda",
  "mediaType":"SSD"
}'

The 200 response returns the ID of the newly added device:

{
  "id":"7bfd3da400000000"
}

Monitor Rebalance

Once the device has been added, PowerFlex automatically rebalances data in the Storage Pool across all devices. The rebalance can be monitored using the following endpoint, focusing on rebalancing statistics:

curl -k -r POST -H "Content-type: application/json" -u <user>:<token> 'https:// ://<PowerFlex-GW-IP>/api/types/StoragePool/instances/action/querySelectedStatistics' -d '
{
  "ids":
    [
      "1d22fd3a00000000"
    ], 
  "properties": 
    [
      "pendingMovingInRebalanceJobs",
      "rebalanceCapacityInKb",
      "activeRebalanceCapacityInKb",
      "rebalanceWriteBwc",
      "pendingRebalanceCapacityInKb",
      "activeMovingRebalanceJobs",
      "pendingMovingRebalanceJobs",
      "rebalanceReadBwc",
      "activeMovingInRebalanceJobs"
    ]
}'

The 200 response contains the specified rebalance statistics for the specified Storage Pool:

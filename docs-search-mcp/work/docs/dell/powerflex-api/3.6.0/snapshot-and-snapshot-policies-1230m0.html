Snapshot and snapshot policies

A snapshot policy facilitates the automation of creating and retaining volume snapshots.

Create a snapshot policy

The following command creates a snapshot policy with a name of ‘snappolA’, and a cadence of 60 minutes. It retains 24 hourly snapshots, seven daily snapshots, and 4our weekly snapshots. The snapshots that are created are unsecured and read-only.

curl -k -r POST -u <user>:<token> -H "Content-Type: application/json" 'https://<PowerFlex-GW-IP>/api/types/SnapshotPolicy/instances' -d  '
{
  "name":"snappolA",
  "numOfRetainedSnapshotsPerLevel":
    [
      "24","7","4"
    ],
  "autoSnapshotCreationCadenceInMin": "60",
  "secureSnapshots": "FALSE",
  "snapshotAccessMode": "ReadOnly"
  }'

The 200 response contains the ID of the new snapshot policy:

{
  "id":"fb4a254900000000"
}

Add a source volume to the snapshot policy

After creating the snapshot policy, add a source volume (or several source volumes) to the snapshot policy. First, obtain the volume ID by running the following and passing the volume name:

curl -v -k -r POST -u <user>:<token> -H "Content-Type: application/json" 'https://<PowerFlex-GW-IP/api/types/Volume/instances/action/queryIdByKey' -d '
{
  "name": "site-b-thick-mg"
}'

The 200 response returns the volume ID:

{
  "id":"dcf736600000000b"
}

Use the following command to add the source volume ID “dcf736600000000b” to snapshot policy “snappolA” with ID “fb4a254900000000” (as the URI path parameter):

curl -k -r POST -u <user>:<token> -H "Content-Type: application/json" 'https://<PowerFlex-GW-IP>/api/instances/SnapshotPolicy::fb4a254900000000/action/addSourceVolumeToSnapshotPolicy' -d '
{
  "sourceVolumeId": "dcf736600000000b"
}'

The 200 response is empty:

{}

Retrieve snapshot policy statistics

The following command displays statistics for the selected snapshot policy, including the source volume IDs:

curl -k -r GET -u <user>:<token> 'https://<PowerFlex-GW-IP /api/instances/SnapshotPolicy::fb4a254900000000/relationships/Statistics'

The 200 response lists the source volume IDs, snapshot statistics, and the IDs of the snapshot volumes:

{
  "srcVolIds": [
      "dcf736600000000b"
    ],
  "numOfAutoSnapshots": 2,
  "numOfExpiredButLockedSnapshots": 0,
  "expiredButLockedSnapshotsIds": [],
  "numOfSrcVols": 1,
  "autoSnapshotVolIds": [
      "dcf738ae00000013",
      "dcf738ad00000012"
  ]
}

Pause the snapshot policy

You can pause the snapshot policy using the following command:

curl -k -r POST -u <user>:<token> 'https://<PowerFlex-GW-IP>/api/instances/SnapshotPolicy::fb4a254900000000/action/pauseSnapshotPolicy'

The 200 response is empty:

{}

Query the snapshot policy state

curl -k -r GET -u <user>:<token> 'https://<PowerFlex-GW-IP>/api/instances/SnapshotPolicy::fb4a254900000000'

Resume a paused snapshot policy

Resume a paused snapshot policy using the following command with the snapshot policy ID as the URI path parameter:

curl -k -r POST -u <user>:<token> 'https://<PowerFlex-GW-IP>/api/instances/SnapshotPolicy::fb4a254900000000/action/resumeSnapshotPolicy'

The 200 response is empty:

{}

Modify a snapshot policy

You can modify a snapshot policy. In this example, the snapshot policy’s cadence is changed from 60 minutes to 30 minutes:

curl -k -r POST -u <user>:<token> -H "Content-Type: application/json" 'https://<PowerFlex-GW-IP>/api/instances/SnapshotPolicy::fb4a254900000000/action/modifySnapshotPolicy' -d '
{
  "numOfRetainedSnapshotsPerLevel": [
    "24","7","4"
  ],
  "autoSnapshotCreationCadenceInMin": "30"
}'

The 200 response is empty:

{}

Remove a source volume from snapshot policy

To remove a source volume, use the source volume ID and specify if the snapshots should be maintained or removed. This example specifies that the snpahots should be removed:

curl -k -r POST -u <user>:<token> -H "Content-Type: application/json" 'https://<PowerFlex-GW-IP>/api/instances/SnapshotPolicy::fb4a254900000000/action/removeSourceVolumeFromSnapshotPolicy' -d '
{
  "sourceVolumeId": "dcf7365d00000008",
  "autoSnapshotRemovalAction": "Remove"
}'

The 200 response is empty:

{}

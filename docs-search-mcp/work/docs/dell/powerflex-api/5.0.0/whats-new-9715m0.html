Changed the following API calls:

Current Previous
/DiscoveryRequest/{refId} PowerFlex Manager 4.6 had this API: /DiscoveryRequest/{id}, which had both GET and DELETE requests. PowerFlex Manager 5.0 does not have the GET request.
/ManagedDevice/{refId}/firmware/compliancereport PowerFlex Manager 4.6 had this API: /ManagedDevice/{refId}/firmware/compliancereport
/ManagedDevice/{refId}/getflexosgatewaymigrateinfo PowerFlex Manager 4.6 had this API: /ManagedDevice/getflexosgatewaymigrateinfo
/osRepository/{refId} PowerFlex Manager 4.6 had this API: /OSRepository/{id}. PowerFlex Manager 5.0 does not have the GET and PUT requests.

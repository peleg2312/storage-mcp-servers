Introduction

Introduction to PowerFlex

PowerFlex is an enterprise-class, software-defined block storage solution that is deployed, managed, and supported as a single system. Highly flexible and scalable, PowerFlex allows you to mix two-layer (Server SAN), single-layer, storage-only, and mixed architectures within a single deployment.

In this release, PowerFlex introduces a new storage platform and architecture based on erasure coding. Erasure coding is a method of data protection that provides improved data durability, resiliency and reliability, and higher capacity usage, which reduces storage overhead. PowerFlex uses dual parity erasure coding, which is implemented using multiple protection schemes based on the number of PowerFlex storage nodes.

PowerFlex Block API

The PowerFlex Block API is installed as part of the PowerFlex installation manager and PowerFlex gateway package. The installation manager manages deployment and upgrades. The PowerFlex gateway leverages role-based security access to expose RESTful APIs for automating frontend and backend storage tasks and core components. the PowerFlex gateway also acts as a gateway for SNMP traps and secure remote services (SRS).

The REST API is served from the PowerFlex gateway through the REST gateway. The PowerFlex Gateway connects to a single metadata manager (MDM) and serves requests by querying the MDM and reformatting the answers it receives from the MDM in a RESTful manner back to a REST client.
Every PowerFlex SCLI command is also available in the PowerFlex REST API. The responses returned by the PowerFlex gateway are in JSON format.

APIs may change as new features are added to the product or changes are made to the PowerFlex software.

Target audience

The PowerFlex Block API is intended for customers who want to automate PowerFlex deployment, configuration, and management tasks.

Basic concepts

The following basic concepts are relevant to the understanding and operation of PowerFlex:

Concept Description
Device A storage device or persistent memory device that is added to a storage system.
Device group A device group consists of devices that come from five or more nodes that are contained in a single protection domain. The nodes that belong to a device group have the same media type.
Device gateway target A device gateway target (DGWT) is a distributed capacity service running on the storage node. The DGWT service processes and saves the data to the devices. The component is accountable for placing data on the storage drives using erasure coding protection schemes.
Metadata manager A metadata manager (MDM) configures and monitors PowerFlex, and is usually configured in redundant cluster mode to support high availability.
PowerFlex data server A PowerFlex data server (PDS) is a storage service that is responsible for processing host I/Os. The PDS service organizes the data within the storage node and divides it into smaller chunks of data of equal size.
Protection domain A protection domain is a logical entity that consists of and manages a group of storage nodes each of which contains devices.
Snapshot A snapshot is a read-only copy of volumes that are used for local data protection. They provide a method of recovery for data that has been corrupted or accidentally deleted.
Storage system A storage system consists of logical entities, such as devices and device groups, storage pools, and NVMe targets, which form the protection domain.
Storage data client A storage data client (SDC) is a lightweight device driver that exposes PowerFlex volumes as block devices to the application that resides on the same server on which the SDC is installed.
Storage node A storage node provide storage capacity, but no compute power for the compute cluster.
Storage pool A storage pool is a logical structure where volumes are created.
Thin clone A thin clone is a read/write copy of a volume or a snapshot that allows changes to content using writes. Thin clones are thin copies of the object from which they were created.
Volume A volume consists of multiple storage blocks spread evenly across devices.

Query selected statistics (POST)

The querySelectedStatistics command allows you to retrieve information about the system.
/api/instances/querySelectedStatistics.

The body of the request reguires the selectedStatisticsList parameter, which is a list of objects containing:

  • type: object type (System, ProtectionDomain, Sds, StoragePool, Device, Volume, VTree, Sdc, FaultSet, AccelerationPool, SpSds, SnapshotPolicy)
  • properties: list of properties to fetch, which are different for each object type

The following parameters are not relevant to the System type and can be omitted from the requet:

  • ids: list of objects ids
    or
  • allIds: with empty value

The response contains a list of all requested types, the IDs, and properties, according to the request parameters.

  • The System type does not contain an ID.
  • Types for which the requested IDs do not exist in the cluster will appear with an empty {}. (See FaultSet in the example below. )
  • Any ID (from the IDs parameters in the request) that does not exist in the cluster will not appear in the response. The following will appear in the scaleio.log file:
    Got no statistics for <type>::<id>.

In the following example, Sds::022beb2300000004 does not exist in the cluster, so it does not appear in the response.

Example:

POST https://localhost:8443/api/instances/querySelectedStatistics

Body:

{"selectedStatisticsList":[{"type":"Sds","ids":["df4bd899000000aa"],"properties":["capacityInUseInKb","rfcachePoolNumOfDriverTheads","snapCapacityInUseInKb","thickCapacityInUseInKb","numOfDevices"]}]}

Response:

{
    "Sds":
        {
    "62b2b5c700000002":
            {
            "snapCapacityInUseInKb": 1048576,
            "rfcachePoolNumOfDriverTheads": 80,
            "thickCapacityInUseInKb": 5595136,
            "capacityInUseInKb": 5595136,
            "numOfDevices": 1
            }
        }
}

Getting Started > PowerFlex Block API

What’s new

The following APIs are added to the PowerFlex Block API for this release:

Device gateway target (DGWT):
  • /api/types/Dgwt/instances
  • /api/types/Dgwt/instances?systemId={system id}&sessionTag={session tag}&lastVersion={last version}
  • /api/instances/Dgwt::{id}
  • /api/instances/StorageNode::{id}/action/ modifyDgwtPort
  • /api/instances/Dgwt::{id}/action/removeDgwt
  • /api/instances/Dgwt::{id}/action/abortRemoveDgwt
Device Group:
  • /api/types/DeviceGroup/instances
  • /api/types/DeviceGroup/instances?systemId={system id}&sessionTag={session tag}&lastVersion={last version}
  • /api/instances/DeviceGroup::{id}
  • /api/types/DeviceGroup /instances
  • /api/instances/DeviceGroup::{id}/action/removeDeviceGroup
  • /api/instances/DeviceGroup::{id}/action/modifyDeviceGroup
  • /api/instances/DeviceGroup::{id}/action/queryUsableCapacity
  • /dtapi/rest/v1/object-inventory
  • /dtapi/rest/v1/metrics/query
Powerflex data server (PDS):
  • /api/types/Pds/instances
  • /api/types/Pds/instances?systemId={system id}&sessionTag={session tag}&lastVersion={last version}
  • /api/instances/StorageNode::{id}/action/modifyPdsPort
  • /api/instances/Pds::{id}/action/removePds
  • /api/instances/Pds::{id}/action/renamePds
Storage node:
  • /api/types/StorageNode/instances
  • /api/types/StorageNode/instances?systemId={system id}&sessionTag={session tag}&lastVersion={last version}
  • /api/instances/StorageNode::{id}
  • /api/instances/StorageNode::{id}/action/removeStorageNode
  • /api/instances/StorageNode::{id}/action/ renameStorageNode
  • /api/instances/StorageNode::{id}/action/addIp
  • /api/instances/StorageNode::{id}/action/modifyIpRole
  • /api/instances/StorageNode::{id}/action/removeIp
  • /api/instances/StorageNode::{id}/action/enterNodeMaintenanceMode
  • /api/instances/StorageNode::{id}/action/queryPortFlappingState
  • /api/instances/StorageNode::{id}/action/vaidateRemoveNode

The following APIs are deprecated from the PowerFlex Block API for this release:

  • Acceleration pool
  • Fault set
  • Host group
  • Protection domain
  • Remote system
  • SnapshotCopyTask
  • Storage data server
  • System network

# Cisco documents to download by hand (cisco.com refuses automated downloads)

cisco.com blocks scripts (bot check), so these are saved from your own browser. For each row: open the PDF link,
save it under the file name shown, into `extra/cisco/<product>/` (the folder named in the section). If a PDF link
answers 404 (some release notes / matrices exist only as a web page), open the page link instead and save it
as "Webpage, HTML Only" under the same name with .html. Then: `python3 sync/import_extra.py --dest work/docs`,
re-index, pack. The page link becomes the document's url in search results.
